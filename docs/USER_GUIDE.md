# 使用指南

[返回 README](../README.md)

## 首次使用

安装与更新优先使用 [README 中的 Homebrew 命令](../README.md#开始使用)，也可手动下载 DMG。更新前退出 Blinker；应用内没有自动更新器。发行包采用 ad-hoc 签名，未使用 Developer ID 或 Apple 公证。首次打开若被拦截，确认来源后到“系统设置 → 隐私与安全性”选择“仍要打开”，详见 [Apple 说明](https://support.apple.com/zh-cn/102445)。

首次打开时会显示引导，介绍应用规则、悬停放大和窗口预览。之后可从“设置 → 通用”重新查看。

引导不会自动申请系统权限：点击辅助功能的“授权…”后，授权助手会打开系统设置，帮助完成授权；需要真实缩略图时，再主动授予屏幕录制权限。不启用录屏也可按图标和标题切换。可以先跳过，稍后在“设置 → 权限”中完成。

## 去哪里改

| 窗口或页面 | 用途 |
|---|---|
| 应用规则 | 添加应用、搜索、开启或暂停该应用的规则、复制与导入导出 |
| 单个应用的编辑窗口 | 配置红、黄、绿灯的点击动作，以及该应用的重映射和悬停开关 |
| 设置 → 通用 | 运行状态、重新查看引导、外观、登录启动、兼容性诊断与最近操作反馈 |
| 设置 → 权限 | 辅助功能与屏幕录制状态、授权助手、重新检查和重新授权指引 |
| 设置 → 悬停放大 | 实时预览、放大尺寸、出现延迟、点击保护、作用范围、扩展按钮与悬停快捷键 |
| 设置 → 窗口预览与切换 | ⌥Tab、Dock 预览、面板大小、窗口缩略图、标签页与窗口过滤 |
| 设置 → 窗口管理 | 拖拽贴靠与窗口布局快捷键 |
| 设置 → 实验功能 | 工作区布局的保存、更新、恢复与删除 |
| 设置 → 关于 | 版本、产品简介、项目、使用说明、反馈与许可 |

## 配置应用规则

点击菜单栏图标进入“应用规则”，按名称或应用标识搜索。添加应用后可双击、按 Return 或点击“编辑规则”打开编辑窗口，无需先运行目标应用。应用库未列出的程序可通过“选择其他应用…”添加。

每颗红绿灯都可以分别设置普通左键、右键、Option 点击、Fn 点击和长按动作。“按钮规则”和“允许悬停放大”可独立开关；悬停还受全局开关及作用范围控制。

点击原生按钮时，未配置的点击交由系统处理。点击悬浮放大按钮时，未配置的普通左键执行原生按钮动作，未配置的右键、Option 点击、Fn 点击和长按不执行操作。显式设置“无操作”会吞掉对应点击。

复制规则保留目标应用的身份，只复制动作及开关。JSON 导入按应用标识合并，同应用的已有规则会被替换；整次导入可撤销。导出包含规则及每应用开关，不包含全局设置、快捷键、权限、窗口图像或工作区布局。

规则文件最多包含 1000 条规则，大小不超过 1 MiB。成功导出的文件可重新导入；超限或无效规则会使导出失败，并保留已有备份文件。多个文件合并后，若总规则超限，需先减少规则才能导出完整备份。

需要临时停用时，使用菜单栏中的当前应用暂停、全部暂停或暂停十分钟。暂停不删除规则。

## 悬停与窗口布局

在“悬停放大”中先查看实时预览，也可打开真实测试窗口。**出现延迟**决定何时显示按钮；**点击保护**决定显示后哪些操作需要等待。两者互不替代。

四个扩展按钮可单独选择动作，设为“不显示”即可隐藏。悬停面板中的布局操作作用于当前悬停的窗口；布局快捷键作用于当前前台窗口。

“窗口管理”提供拖拽贴靠和快捷键设置。拖拽贴靠默认关闭。再次最大化可恢复先前尺寸；“还原上次布局”只还原本次运行中已成功执行的布局操作，不还原文稿内容。

窗口管理和悬停开关快捷键若注册失败，会在对应行显示原因并保留已配置组合；关闭冲突应用后点击“重试注册”，或更换组合。这不能识别所有被系统截获的快捷键；注册成功但无响应时，也需检查系统快捷键设置。

## 窗口、标签页与缩略图

- **⌥Tab**：按住 Option，反复按 Tab 选择，Shift 反向；松开 Option 或按 Return 激活，Esc 取消。面板获得键盘焦点时，也可用方向键选择、⌘W 关闭窗口、⌘M 最小化。
- **Dock 预览**：悬停图标后显示该应用的窗口。出现和移出关闭延迟都可调；移入预览时保持展开，便于点击。
- **大小**：设置页或预览底部菜单调整 50% 至 150%。缩略图、标题、按钮与外框一起缩放。内容在同一面板排列，超出屏幕可用空间时滚动。
- **显示标签页**：开启后，标准 macOS 窗口标签栏（如访达、文本编辑）和 Safari 标签页可独立列出。自绘标签栏暂不保证支持；关闭后按窗口显示。
- **后台与最小化**：优先显示各自的缓存图像；系统无法提供新画面时显示图标与标题。后台标签页不会借用当前标签页的缩略图。

点击标签项会切换到对应标签；“关闭窗口”“最小化”等动作仍作用于整个所属窗口。

## 权限与排障

### 授权助手

“设置 → 权限”和首次引导共用授权助手。点击“授权…”会请求对应权限并打开系统设置；“管理权限…”和“重新授权…”也可打开助手。首次请求是否弹窗由 macOS 决定，曾拒绝后可能需要直接在系统设置中开启。

助手会留在屏幕上，提供正在运行的 Blinker 应用图标。系统列表没有 Blinker 时，可尝试将图标拖入；若无法拖入，点击“在访达中显示”，再通过系统列表下方的加号选择该应用。拖入只帮助添加应用，仍需在系统设置中确认允许。若无法直接打开权限页面，手动前往“系统设置 → 隐私与安全性”选择对应权限。

返回 Blinker 时会自动检查状态，也可点击“重新检查权限”。打开设置或完成拖拽不代表已经授权。助手不会自动重置或修改系统授权；“重新授权…”只提供操作指引。

### 辅助功能

在“设置 → 权限”的辅助功能一项点击“授权…”，到“系统设置 → 隐私与安全性 → 辅助功能”开启 Blinker。该权限用于读取窗口控件和执行操作。“通用”在缺少权限时也提供“授权辅助功能…”入口。

无响应时，先在“通用”检查运行状态，再使用“检查应用兼容性”或真实测试窗口区分权限问题与目标应用支持问题。应用的保存确认对话框仍由其自身处理。

升级或更换签名后，已显示开启的授权也可能需要更新。点击辅助功能的“重新授权…”，按助手提示操作：

1. 确认正在运行的应用路径，避免同时运行发行版和开发版。
2. 在系统列表中关闭再开启 Blinker；若仍无效，移除旧条目，再通过助手图标或加号添加并启用当前应用。
3. 返回 Blinker 重新检查权限；仍无响应时退出并重新打开，再检查“通用”的运行状态。

### 屏幕录制

只有窗口缩略图需要屏幕录制权限。在“设置 → 权限”的屏幕录制一项点击“授权…”，或在“窗口预览与切换”点击“授权窗口缩略图…”，按助手提示在系统设置中允许 Blinker 录制屏幕。部分系统将此页面称为“屏幕与系统音频录制”，仅允许音频不足以生成缩略图。

授权后返回 Blinker 重新检查；如果系统提示退出并重新打开，或仍无法读取缩略图，请重启 Blinker 后再试。已经授权但仍无效时，可打开该项的“重新授权…”指引。

不开启缩略图也能按图标和标题切换。玻璃底托、按钮放大和窗口布局不依赖录屏权限。关闭缩略图会清除内存图像缓存；图片不写入磁盘。

### 兼容性边界

安全输入、应用自身的辅助功能实现和自绘控件会影响支持程度。其他桌面的窗口、已最小化的画面与布局最小尺寸由系统及目标应用决定。报告问题时附上 macOS 版本、应用名、触发方式和诊断结果；分享截图或导出规则前检查其中是否包含不想公开的应用、窗口标题或内容。

## 实验工作区

启用实验功能后，可以保存当前窗口排布并恢复。它只管理已有窗口，不会重新打开已退出应用、文稿或网页。同应用的相似窗口可能匹配错误；“恢复时移回原桌面”依赖非公开系统接口，系统变化可能使其不可用。关闭实验开关会保留已保存布局。
