# 使用指南

[返回 README](../README.md)

## 首次使用

首次打开时会显示引导，介绍应用规则、悬停放大和窗口预览。之后可从“设置 → 通用”重新查看。

引导不会自动申请系统权限：点击辅助功能授权按钮后，按系统提示允许 Blinker 识别和操作窗口；需要真实缩略图时，再主动点击屏幕录制授权按钮。不启用录屏也可按图标和标题切换。授权后可重新检查状态，也可先跳过，稍后在设置中完成。

## 去哪里改

| 窗口或页面 | 用途 |
|---|---|
| 应用规则 | 添加应用、搜索、开启或暂停该应用的规则、复制与导入导出 |
| 单个应用的编辑窗口 | 配置红、黄、绿灯的点击动作，以及该应用的重映射和悬停开关 |
| 设置 → 通用 | 运行状态、重新查看引导、外观、登录启动、兼容性诊断与最近操作反馈 |
| 设置 → 悬停放大 | 实时预览、放大尺寸、出现延迟、点击保护、作用范围、扩展按钮与悬停快捷键 |
| 设置 → 窗口预览与切换 | ⌥Tab、Dock 预览、面板大小、窗口缩略图、标签页与窗口过滤 |
| 设置 → 窗口管理 | 拖拽贴靠与窗口布局快捷键 |
| 设置 → 实验功能 | 工作区布局的保存、更新、恢复与删除 |
| 设置 → 关于 | 版本、产品简介、项目、使用说明、反馈与许可 |

## 配置应用规则

点击菜单栏图标进入“应用规则”，按名称或应用标识搜索。添加应用后可双击、按 Return 或点击“编辑规则”打开编辑窗口，无需先运行目标应用。应用库未列出的程序可通过“选择其他应用…”添加。

每颗红绿灯都可以分别设置普通左键、右键、Option 点击、Fn 点击和长按动作。未配置的点击方式保留系统行为；“无操作”会吞掉该次点击。“按钮规则”和“允许悬停放大”可独立开关；悬停还受全局开关及作用范围控制。

复制规则保留目标应用的身份，只复制动作及开关。JSON 导入按应用标识合并，同应用的已有规则会被替换；整次导入可撤销。导出包含规则及每应用开关，不包含权限、窗口图像或布局历史。

需要临时停用时，使用菜单栏中的当前应用暂停、全部暂停或暂停十分钟。暂停不删除规则。

## 悬停与窗口布局

在“悬停放大”中先查看实时预览，也可打开真实测试窗口。**出现延迟**决定何时显示按钮；**点击保护**决定显示后哪些操作需要等待。两者互不替代。

四个扩展按钮可单独选择动作，设为“不显示”即可隐藏。悬停面板中的布局操作作用于当前悬停的窗口；布局快捷键作用于当前前台窗口。

“窗口管理”提供拖拽贴靠和快捷键设置。拖拽贴靠默认关闭。再次最大化可恢复先前尺寸；“还原上次布局”只还原本次运行中已成功执行的布局操作，不还原文稿内容。

## 窗口、标签页与缩略图

- **⌥Tab**：按住 Option，反复按 Tab 选择，Shift 反向；松开 Option 或按 Return 激活，Esc 取消。面板获得键盘焦点时，也可用方向键选择、⌘W 关闭窗口、⌘M 最小化。
- **Dock 预览**：悬停图标后显示该应用的窗口。出现和移出关闭延迟都可调；移入预览时保持展开，便于点击。
- **大小**：设置页或预览底部菜单调整 50–150%。缩略图、标题、按钮与外框一起缩放。内容在同一面板排列，超出屏幕可用空间时滚动。
- **显示标签页**：开启后，标准 macOS 窗口标签栏（如访达、文本编辑）和 Safari 标签页可独立列出。自绘标签栏暂不保证支持；关闭后按窗口显示。
- **后台与最小化**：优先显示各自的缓存图像；系统无法提供新画面时显示图标与标题。后台标签页不会借用当前标签页的缩略图。

点击标签项会切换到对应标签；“关闭窗口”“最小化”等动作仍作用于整个所属窗口。

## 权限与排障

### 辅助功能

前往“系统设置 → 隐私与安全性 → 辅助功能”为正在运行的 Blinker 授权。该权限用于读取窗口控件和执行操作。

无响应时，先在“通用”检查运行状态，再使用“检查应用兼容性”或真实测试窗口区分权限问题与目标应用支持问题。应用的保存确认对话框仍由其自身处理。

升级或更换签名后，已显示开启的授权也可能需要更新：

1. 确认正在运行的应用路径，避免同时运行发行版和开发版。
2. 退出 Blinker，在辅助功能列表中移除旧条目，再添加并启用当前应用。
3. 重新启动 Blinker，检查“通用”的状态。

通常无需重置系统权限库。若确需使用 `tccutil`，只重置相应应用的辅助功能授权：

```bash
# 发行版
tccutil reset Accessibility com.ygnstudio.Blinker
# 本地开发版；仅在使用开发版时执行
tccutil reset Accessibility com.ygnstudio.Blinker.dev
```

重置后需要重新授权。请勿执行不带应用标识的全局重置。

### 屏幕录制

只有窗口缩略图需要屏幕录制权限。在“窗口预览与切换”点击“授权窗口缩略图…”，按系统提示完成，再点击“重新检查权限”；如系统要求重启应用，重启后再试。

不开启缩略图也能按图标和标题切换。玻璃底托、按钮放大和窗口布局不依赖录屏权限。关闭缩略图会清除内存图像缓存；图片不写入磁盘。

### 兼容性边界

安全输入、应用自身的辅助功能实现和自绘控件会影响支持程度。其他桌面的窗口、已最小化的画面与布局最小尺寸由系统及目标应用决定。报告问题时附上 macOS 版本、应用名、触发方式和诊断结果；分享截图或导出规则前检查其中是否包含不想公开的应用、窗口标题或内容。

## 实验工作区

启用实验功能后，可以保存当前窗口排布并恢复。它只管理已有窗口，不会重新打开已退出应用、文稿或网页。同应用的相似窗口可能匹配错误；“恢复时移回原桌面”依赖非公开系统接口，系统变化可能使其不可用。关闭实验开关会保留已保存布局。
