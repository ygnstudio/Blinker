# 使用指南

[返回 README](../README.md)

## 首次使用

安装与更新优先使用 [README 中的 Homebrew 命令](../README.md#安装与更新)，也可手动下载 DMG。更新前退出 Blinker；应用内没有自动更新器。发行包采用 ad-hoc 签名，未使用 Developer ID 或 Apple 公证。首次打开若被拦截，确认来源后到“系统设置 → 隐私与安全性”选择“仍要打开”，详见 [Apple 说明](https://support.apple.com/zh-cn/102445)。

首次打开时会显示引导，介绍应用规则、悬停放大和窗口预览。之后可从“设置 → 通用”重新查看。

引导不会自动申请系统权限：点击辅助功能的“授权…”后，授权助手会打开系统设置，帮助完成授权；需要真实缩略图或 Duo 开合盖效果时，再主动授予屏幕录制权限。不启用录屏也可按图标和标题切换。可以先跳过，稍后在“设置 → 隐私与权限”中完成。

## 去哪里改

| 设置 → 屏幕特效 | Duo 开合盖效果、模拟预览、真实角度与校准、触发和画面参数 |

| 设置 → 快捷键 | 布局、悬停开关和显示桌面快捷键、注册错误与重试；查看 ⌥Tab 状态并前往其设置 |

“通用”的“启用窗口增强”控制窗口按钮、悬停、预览、布局和桌面操作；状态图标与 Duo 屏幕特效独立运行，各自在所属页面调整。

## 外观与语言

在“设置 → 通用 → 外观与语言”中选择跟随系统、浅色或深色。外观立即生效，设置、辅助窗口、悬停按钮和预览均跟随所选外观。

语言默认跟随系统，也可选择“简体中文”或“English”。更改后退出并重新打开 Blinker，让菜单、窗口和操作提示使用一致的语言。语言选择只对 Blinker 生效；改回“跟随系统”会移除本应用的语言覆盖，不会修改系统语言。

## 状态图标与面板

单击菜单栏图标默认打开状态面板，也可在“设置 → 状态图标 → 图标”改为直接打开“应用规则”。右键菜单保留系统状态、应用规则、设置、暂停和退出入口。图标可只放在菜单栏、只放在 Dock，或同时显示。菜单栏单击动作只影响菜单栏图标；点击 Blinker 自身的 Dock 图标会打开状态面板。

- 外圈表示电量。默认低于 20% 时为红色；否则，低电量模式为黄色，充电或接电为绿色。可调整阈值、关闭状态颜色，并选择电量数字、充电标记或中央电量。
- 中间表示 Wi-Fi 信号或有线连接。Wi-Fi 关闭时显示斜杠，无法确认连接状态时显示问号；有线连接优先显示。它表示本机连接状态，不验证互联网是否可访问。
- 底部默认用四个圆点表示音量，也可改为弧线。静音或零音量时变淡；无法读取音量时使用未知状态图形。

“设置 → 状态图标”分为四类：

| 分类 | 可调整内容 |
|---|---|
| 图标 | 显示位置、菜单栏尺寸、线条粗细、Dock 背景、左键动作和定期刷新间隔 |
| 电池 | 百分比位置、接电标记、标记大小、状态颜色与阈值、菜单栏充电光效和闪电呼吸 |
| 网络与音量 | 网络和蓝牙音频图形、网络异常优先、音量圆点或弧线及蓝牙强调色 |
| 状态面板 | 区块显示与顺序、输出设备数量及顺序、滚动音量的响应范围、增大方向和自然滚动 |

顶部预览使用与实际图标相同的渲染器，提供所选尺寸、放大示意和 Dock 样例。可查看当前状态，或选择明确标注的模拟情景检查颜色和图形；模拟情景不会更改系统状态。菜单栏尺寸可设为 16 至 36 pt，实际显示还受系统菜单栏高度限制。图标前景色跟随菜单栏背景，Dock 背景单独设置；预览背景不会改变系统外观。

菜单栏图标、设置中的实际尺寸和放大示意共用充电动画，Dock 图标保持静态。低电量模式、系统“减少动态效果”和睡眠时停止动画；关闭“菜单栏充电光效”也会停止闪电呼吸。恢复默认设置前会请求确认。

状态面板的音量区可拖动滑块、切换静音和选择输出设备，也可在启用后滚动调节音量。滚动只在面板中所选的范围内响应，设备列表仍用于正常滚动。设备不支持系统音量或静音控制时，对应控件不可用；读取或写入失败会显示错误，可刷新后重试。

在“状态面板”中用上下按钮调整输出设备顺序，不会切换设备。面板按同一顺序显示设备，当前输出的名称在音量控件上方单独显示；可限制初始显示数量，或始终显示全部。面板区块可以全部关闭，底部仍保留应用规则和设置入口。

网络与电源区提供系统设置入口。蓝牙音频图形只根据当前输出设备类型显示，不提供附近设备扫描、已配对设备管理、VPN 管理或 Wi-Fi 名称读取。这些状态与音量功能不新增权限请求，无内置电池的 Mac 仍可使用网络和音量功能。

部分实现改编自 Status Trio，来源及修改说明见[第三方声明](../ThirdParty/StatusTrio/README.md)。在“关于”窗口打开许可证页，可离线查看 Blinker 的 GPLv3 及 Status Trio 的 Apache 2.0 全文。

## 配置应用规则

从状态面板或右键菜单进入“应用规则”，按名称或应用标识搜索。添加应用后可双击、按 Return 或点击“编辑规则”打开编辑窗口，无需先运行目标应用。应用库未列出的程序可通过“选择其他应用…”添加。

每颗红绿灯都可以分别设置普通左键、右键、Option 点击、Fn 点击和长按动作。“启用选项”中的两个开关分别控制按钮规则和悬停显示，关闭后保留配置；悬停还受全局开关及作用范围控制。编辑窗口显示可选中复制的应用标识，规则列表仍可按该标识搜索。

动作菜单中的默认项因点击方式而异：

- 普通左键的“系统默认”保留原生按钮动作，悬浮按钮也会执行该动作。
- 右键、Option 点击和 Fn 点击的“未配置”让原生按钮交由系统处理；在悬浮按钮上不执行操作。
- 长按的“未配置”按普通左键处理。要在原生按钮上使用独立长按动作，目前还需配置该按钮的普通左键动作。
- 显式选择“无操作”会拦截对应点击，不执行动作。

单个应用编辑窗口的“规则操作”保留撤销、重做、从其他应用复制和恢复默认设置。复制保留目标应用的身份，只复制动作及开关。全局 JSON 导入导出位于“应用规则”列表的工具菜单中：导入按应用标识合并，同应用的已有规则会被替换；实际发生修改的导入可整次撤销。空文件或与现有规则相同的文件会显示“规则没有变化”，保留先前的撤销记录。导出包含规则及每应用开关，不包含全局设置、快捷键、权限、窗口图像或工作区布局。

规则文件最多包含 1000 条规则，大小不超过 1 MiB。成功导出的文件可重新导入；超限或无效规则会使导出失败，并保留已有备份文件。多个文件合并后，若总规则超限，需先减少规则才能导出全部规则。

需要临时停用时，使用菜单栏中的当前应用暂停、全部暂停或暂停十分钟。暂停不删除规则。

## 悬停与窗口布局

在“悬停按钮”中先查看实时预览，也可打开真实测试窗口。**出现延迟**决定何时显示按钮；**点击保护**决定显示后哪些操作需要等待。两者互不替代。

鼠标移入某颗按钮时，按钮轻微放大，移出后恢复；点击范围保持不变。设置中的预览也支持这个效果，点击预览按钮不会操作窗口。

四个扩展按钮可单独选择动作，设为“不显示”即可隐藏。悬停面板中的布局操作作用于当前悬停的窗口；布局快捷键作用于当前前台窗口。

“窗口管理”提供 Dock 点击收起、显示桌面、拖拽贴靠和实验工作区。拖拽贴靠默认关闭。再次最大化可恢复先前尺寸；“还原上次布局”只还原本次运行中已成功执行的布局操作，不还原文稿内容。

“快捷键”集中配置窗口布局、悬停开关和显示桌面的按键组合，三者共用“启用布局、悬停与桌面快捷键”开关。⌥Tab 独立启用，仍在“预览与切换”中设置。录制时暂时释放这组快捷键，再次点击同一组合或按 Esc 取消，减号清除已有组合；切换设置页面会结束录制。

布局、悬停或桌面快捷键若注册失败，会在对应行显示原因并保留已配置组合；关闭冲突应用后点击“重试注册”，或更换组合。这不能识别所有被系统截获的快捷键；注册成功但无响应时，也需检查系统快捷键设置。

## Dock 点击收起与显示桌面

在“设置 → 窗口管理”开启“点击 Dock 图标收起窗口”后，点击当前前台应用的 Dock 图标，会最小化它在当前桌面的普通窗口；再次点击只恢复由这项功能收起的窗口。开关默认关闭；点击其他应用仍先按系统方式打开或激活。右键、修饰键点击和拖拽保留系统行为。

“显示桌面”会收起当前桌面可操作的普通窗口；再次执行“恢复窗口”只恢复本次成功收起的窗口。可使用“窗口管理”中的按钮，或默认 ⌃⌥D 快捷键；在“快捷键 → 桌面”可以更改或清除组合。该快捷键不占用访达的 ⌘D。

两项功能都需要辅助功能权限，无需屏幕录制。它们不处理全屏窗口，也不会恢复操作前就已最小化的窗口。切换桌面后会清除上一桌面的批量恢复记录，避免把窗口带回错误桌面；已收起的窗口仍可从系统 Dock 打开。全部暂停会停止这些操作，不修改已保存的开关或快捷键。

## 窗口、标签页与缩略图

“设置 → 预览与切换”按触发方式与共用设置分成四组：

| 分组 | 设置范围 |
|---|---|
| 键盘窗口切换 | ⌥Tab 的独立开关与快捷键状态 |
| Dock 悬停预览 | 悬停开关及其出现、关闭延迟；关闭悬停时，两个延迟不可调 |
| 共用的显示内容 | 标签页、最小化与隐藏窗口、当前显示器范围 |
| 共用的预览外观 | 整个面板的大小、窗口缩略图及其录屏授权提示、手动打开面板 |

关闭 ⌥Tab 或 Dock 悬停只停用对应入口，手动窗口面板仍可使用，共用设置仍可调整。标签页与窗口范围也不依赖缩略图开关；关闭缩略图后仍按图标和标题显示。

- **⌥Tab**：按住 Option，反复按 Tab 选择，Shift 反向；松开 Option 或按 Return 激活，Esc 取消。面板获得键盘焦点时，也可用方向键选择、⌘W 关闭窗口、⌘M 最小化。
- **Dock 预览**：悬停图标后显示该应用的窗口。出现和移出关闭延迟都可调；移入预览时保持展开，便于点击。
- **过渡效果**：预览出现和关闭时短暂淡入淡出，切换选中项和打开窗口立即响应。系统开启“减少动态效果”时，取消这些过渡和按钮缩放。
- **大小**：设置页或预览底部菜单调整 50% 至 150%。缩略图、标题、按钮与外框一起缩放。内容在同一面板排列，超出屏幕可用空间时滚动。
- **显示标签页**：开启后，标准 macOS 窗口标签栏（如访达、文本编辑）和 Safari 标签页可独立列出。自绘标签栏暂不保证支持；关闭后按窗口显示。
- **后台与最小化**：优先显示各自的缓存图像；系统无法提供新画面时显示图标与标题。后台标签页不会借用当前标签页的缩略图。

若出现“缩略图暂不可用”，可点击“重试”；窗口仍可按图标和标题切换。后台标签页没有缓存画面时显示图标，属于正常情况。

点击标签项会切换到对应标签；“关闭窗口”“最小化”等动作仍作用于整个所属窗口。

## Duo 开合盖效果

Duo 默认关闭。在带兼容开合角度传感器的 MacBook 上，开盖和合盖都可触发内置屏幕效果：在有效角度范围内，合盖时逐渐增强倾斜、模糊和暗化，开盖时逐渐减弱并恢复画面。外接显示器不播放此效果。找不到传感器或无法读取角度时，设置页会明确显示状态，不会用模拟角度代替真实读数。

在“设置 → 屏幕特效”中，先拖动顶部“模拟合盖”滑块查看效果。预览使用生成的示意画面，不读取屏幕，也不会开启真实效果。把屏幕放在舒适角度，点击“校准为当前角度”，再按需开启“启用 Duo 开合盖效果”。校准与参考角度位于“校准与强度”；触发幅度、动画结束方式和 Duo 画面分别分组。真实效果需要屏幕录制权限，可点击“授权屏幕特效…”打开共用授权助手；已经授权窗口缩略图时无需另授一份权限。

“开合触发幅度”可设为 3 至 15°，数值越大，越容易忽略小幅晃动；旧配置中的 1°、2°会按 3°处理。每次都要从本轮角度基线向开盖或合盖方向移动足够幅度，并经过短暂确认才会启动。“参考角度”和“满效果跨度”用于计算效果强度，与本轮动作的判断基线分开。

“清除延时”调整停稳后的淡出等待，小幅往返晃动不会让效果一直延续。连续开合不必先停稳，改变方向仍需满足触发幅度和短暂确认。普通结束会逐渐淡出，淡出中继续有效动作可以接续画面；开启“保持特效直到重新打开”会取消自动清除，重新打开至效果起点仍会恢复。

“动画速度”可设为 25% 至 200%，100% 为原速。它只调整画面过渡的快慢，不改变传感器采样频率、开合触发幅度或清除延时。Duo 画面还可分别调整后仰、雾面、暗化、模糊和边界过渡。恢复默认设置会关闭效果并重置校准及参数，执行前需确认。

点击“应用推荐参数”可采用这组起点继续微调：触发幅度 6°、满效果跨度 45°、清除延时 0.6 秒、动画速度 100%、“保持特效直到重新打开”关闭，后仰 60°、雾面 72%、暗化 21%、模糊 41%、边界过渡 75%。应用时保留当前启用状态和已校准的参考角度。新安装默认使用这组参数，参考角度为 110°，效果仍关闭；已有配置不会被自动覆盖。

可在设置或菜单中暂停、继续效果。按 Esc 也可暂停；在其他应用中接收 Esc 需要辅助功能权限，未授权时仍可使用菜单。暂停、锁屏、休眠、检测到权限失效、传感器失效或屏幕捕获中断时会立即移除画面，系统开启“减少动态效果”时暂停运行。

画面只在本机内存中处理，不采集音频、不保存录像。该功能不改变正常合盖睡眠，也不是隐私防护。实现来源和 MIT 许可见 [Duo Effect 第三方说明](../ThirdParty/MacbookDuoEffect/README.md)；“关于”的许可证页可离线查看全文。

## 权限与排障

### 授权助手

“设置 → 隐私与权限”集中管理授权状态，和首次引导共用授权助手。点击“授权…”会请求对应权限并打开系统设置；“管理权限…”和“授权后仍无法使用”中的重新授权按钮也可打开助手。首次请求是否弹窗由 macOS 决定，曾拒绝后可能需要直接在系统设置中开启。

助手会留在屏幕上，提供正在运行的 Blinker 应用图标。系统列表没有 Blinker 时，可尝试将图标拖入；若无法拖入，点击“在访达中显示”，再通过系统列表下方的加号选择该应用。拖入只帮助添加应用，仍需在系统设置中确认允许。若无法直接打开权限页面，手动前往“系统设置 → 隐私与安全性”选择对应权限。

返回 Blinker 时会自动检查状态，也可点击“重新检查权限”。打开设置或完成拖拽不代表已经授权。助手不会自动重置或修改系统授权；“重新授权…”只提供操作指引。

### 辅助功能

在“设置 → 隐私与权限”的辅助功能一项点击“授权…”，到“系统设置 → 隐私与安全性 → 辅助功能”开启 Blinker。该权限用于读取窗口控件和执行操作。“通用”在缺少权限时也提供“授权辅助功能…”入口。

无响应时，先在“通用”检查运行状态，再从“帮助”菜单打开“检查应用兼容性”或真实测试窗口，区分权限问题与目标应用支持问题。单个应用的规则编辑窗口也可检查兼容性。应用的保存确认对话框仍由其自身处理。

升级或更换签名后，已显示开启的授权也可能需要更新。在“隐私与权限”展开“授权后仍无法使用”，点击“重新授权辅助功能…”，按助手提示操作：

1. 确认正在运行的应用路径，避免同时运行发行版和开发版。
2. 在系统列表中关闭再开启 Blinker；若仍无效，移除旧条目，再通过助手图标或加号添加并启用当前应用。
3. 返回 Blinker 重新检查权限；仍无响应时退出并重新打开，再检查“通用”的运行状态。

### 屏幕录制

窗口缩略图和 Duo 开合盖效果共用屏幕录制权限。在“设置 → 隐私与权限”的屏幕录制一项点击“授权…”，或从“预览与切换”的“授权窗口缩略图…”、“屏幕特效”的“授权屏幕特效…”打开助手，按提示在系统设置中允许 Blinker 读取屏幕画面。部分系统将此页面称为“屏幕与系统音频录制”，仅允许音频不足以生成缩略图或 Duo 效果。

授权后返回 Blinker 重新检查；如果系统提示退出并重新打开，或仍无法读取画面，请重启 Blinker 后再试。已经授权但仍无效时，可在“隐私与权限”展开“授权后仍无法使用”，打开“重新授权屏幕录制…”指引。

不开启缩略图也能按图标和标题切换。玻璃底托、按钮放大和窗口布局不依赖录屏权限。缩略图与 Duo 的功能开关各自独立：关闭缩略图会清除其内存图像缓存，不会关闭已启用的 Duo。两者都不将屏幕画面写入磁盘，也不采集音频。

### 兼容性边界

安全输入、应用自身的辅助功能实现和自绘控件会影响支持程度。其他桌面的窗口、已最小化的画面与布局最小尺寸由系统及目标应用决定。报告问题时附上 macOS 版本、应用名、触发方式和诊断结果；分享截图或导出规则前检查其中是否包含不想公开的应用、窗口标题或内容。

## 实验工作区

在“设置 → 窗口管理”的“工作区（实验）”中启用后，可保存和恢复当前可识别窗口的排布，包括最小化和其他桌面的窗口。它只管理已有窗口，不会重新打开已退出应用、文稿或网页。同应用的相似窗口可能匹配错误；“恢复时移回原桌面”依赖非公开系统接口，系统变化可能使其不可用。关闭实验开关会保留已保存布局。
