# Blinker 设计规范

版本：2026-10-07 · 全原生控件与系统尺寸规范。用户明确要求：全部原生，不保留自定义控件。

**以 macOS 26–27 原生风格和使用方式为准。** SwiftUI/AppKit 的系统控件、Liquid Glass 侧栏与工具栏、焦点、键盘和窗口行为优先于 HTML 示意。正文在浅色和深色下均保持稳定可读；最低系统为 macOS 26，支持目标为 26–27，取消 26 之前的系统材质回退。所有交互控件、容器外观与反馈使用系统实现；不保留自绘控件、圆角或 UI 动效 token。不覆写系统固有外形、尺寸和转场。

本文是唯一生效的 UI/UX 规范，适用于规则、设置、状态面板、快速操作及后续新增功能。`DESIGN.md` 仅作入口，不另存一套规则。本文表达设计要求，不等于全部功能已经完成或验收通过。

- 实现和验证记录：[macOS 26–27 审查](docs/macos26-ui-audit.md)。每条结果只对应其构建与场景。
- 历史材料：[初始审查](docs/ui-system-proposal.md)、[历次修订](docs/ui-design-history.md)、[HTML 设计稿](docs/ui-system-preview.html)。它们不覆盖现行规则，也不证明原生材质效果。
- 后续用户确认改变规则时，在对应章节修改原条目，并将旧结论移入历史记录；不在文末追加另一套“当前修订”。实现暂未遵守的地方记为差异或待办，不为迁就代码偷偷修改规则。

### 执行速查

| 事项 | 统一规定 |
|---|---|
| 窗口 | 一个管理窗口；规则和设置互斥两栏，不增加第三栏或第二个普通编辑窗口 |
| 导航 | 工作区切换固定在侧栏顶部；搜索在规则列表上方；侧栏收放在详情工具栏左侧 |
| 标题 | 规则页不重复应用名；设置保留页面名；状态面板只保留一套页签导航 |
| 材质 | 使用系统容器与原生材质；不手绘玻璃、叠固定 alpha 遮罩或分组卡片 |
| 分组 | 一个内容组只有一层表面；先用标题和间距，避免圆角卡、描边、横线同时堆叠 |
| 控件 | 全部采用原生控件和系统 style；同语义同组件，不保留自绘选择卡或页签 |
| 大小 | 控件默认 regular 与系统固有尺寸；窗口及业务布局遵循第 7.2 节 |
| 动效 | 系统反馈与默认转场；没有原生转场时直接切换，不补自定义淡入或弹跳 |
| 状态 | 操作立即反馈；加载、空、失败、无权限、成功按实际能力定义；不能用动画掩盖等待 |
| 扩展 | 先确定功能归属、状态拥有者、配置与执行入口，再接入既有组件与验收矩阵 |


## 1. 实施范围

规则、偏好、工作区和权限诊断复用一个管理窗口；删除独立应用规则编辑容器。现有配置 key、权限边界和业务控制器保留；网络、声音、图标优先级分别编辑及重置。侧栏分组可折叠，外部跳转展开对应组。规则单击编辑，选择在切页间保留。屏幕特效、清洁模式、真实测试窗口和授权助手继续承担各自独立任务。

后续新功能应按下文的唯一归属、共享组件和状态要求接入，不能添加第二套编辑器或无内容的占位分类。

## 2. 窗口整合

| 界面 | 目标容器 | 规则 |
|---|---|---|
| 应用规则、所有设置、工作区、兼容性检查 | 同一个「Blinker」管理窗口 | 统一导航状态，所有入口复用现有窗口并定位到目的地；恢复最小化窗口，不重置位置和尺寸 |
| 单应用规则编辑 | 主窗口的应用列表 + 编辑区 | 单击应用直接编辑；取消默认独立编辑窗口和「设置/规则」互相开窗按钮。旧入口重定向到 `rules(appID)` |
| 状态 / 快速操作 | 同一面板的两个页签 | 菜单栏弹出与 Dock 打开共享模型和组件；一次只展示一种承载方式，关闭面板不取消已接受的命令 |
| 授权助手 | 独立辅助面板 | 需要和系统设置并排、拖动应用图标；按权限复用同一面板，完成后可关闭 |
| 真实窗口测试 | 独立测试窗口 | 原生红绿灯本身是测试对象，不能改成截图或主窗口内容卡 |
| 悬停按钮、Dock 预览、⌥Tab、操作反馈 | 上下文浮层/HUD | 保持锚点、键盘和窗口层级，不能塞进管理窗口 |
| 清洁模式、开合盖特效 | 功能覆盖层 | 保留退出方式及权限边界；与原生 UI 转场分开 |
| 首次引导 / 重新查看引导 | 首次引导窗口 / 主窗口 sheet | 完成或关闭后回到指定目的地，不叠加第二套管理窗口 |
| 关于 / 许可证 | 系统「关于」入口复用一个窗口；许可证 sheet | 无需为整合强行取消标准系统入口；应用配置只有一份 |
| 保存工作区、导入冲突、危险重置 | 依附发起窗口的 sheet / alert | 普通编辑不弹窗；只有短事务、选择文件和确认使用 sheet |

主窗口默认 920×620pt，最低 760×480pt。始终采用两栏：侧栏顶部固定「应用规则 / 设置」导航。规则区在导航下依次放置原生搜索框、应用列表，旁边为编辑区；设置区在导航下显示分类列表，旁边为页面内容。侧栏宽 180–240pt。两种侧栏互斥，不同时展示，不嵌套 NavigationSplitView。切换保留所选应用和上次设置目的地。应用列表仅显示图标与名称，状态由编辑区开关和辅助功能表达。规则页顶部不重复显示所选应用名称；保留侧栏收放按钮。两页的收放按钮共用组件，挂在详情栏工具栏内，位于侧栏分隔线右侧，不用固定间距补位。规则文件操作反馈也归属详情栏，避免外层安全区改变分栏工具栏布局。设置页保留原有页面标题。每栏独立滚动。

`⌘,` 定位通用；菜单「应用规则」定位上次选择应用；模块配置链接直接定位对应页面。关闭主窗口不退出菜单栏应用。修改导航必须先结束快捷键录制，保存有效输入并保留无效草稿；不能为了转场重建业务控制器。

## 3. 功能全量归组与唯一归属

侧栏四组：窗口、状态与操作、屏幕、应用。组可折叠；记住展开状态，外部跳转自动展开目标组。每组最多一层页面，不使用侧栏、页面页签、内嵌侧栏三套重复导航。工作区为窗口组中有独立内容模型的管理页，标注「实验」。新增功能优先加入已有领域，不能直接平铺到侧栏末尾。

| 目标页面 | 归入的现有功能 | 执行 / 配置边界 |
|---|---|---|
| 侧栏顶部 / 应用规则 | 添加/搜索/启用规则；红黄绿灯动作、修饰键、例外；复制、恢复、撤销/重做、导入/导出；兼容性入口 | 应用级行为只在规则编辑区修改；高级动作折叠，保留真实值 |
| 窗口 / 悬停按钮 | 放大启用、尺寸、出现延迟、作用范围、点击保护、额外按钮、真实测试 | 快捷键只显示当前绑定并跳到快捷键页；测试是明确的「测试」按钮 |
| 窗口 / 预览与切换 | ⌥Tab 启用与冲突、Dock 悬停与进出延迟、标签页、隐藏/最小化窗口、显示器范围、缩略图/大小 | ⌥Tab 唯一启用开关在此；手动打开面板属于预览测试 |
| 窗口 / 布局与桌面 | 拖动贴靠、Dock 再次点击收起、桌面行为；布局快捷键入口 | 日常「显示桌面/恢复窗口」移至快速操作；此页留配置、权限和命名明确的测试 |
| 窗口 / 快捷键 | 桌面、悬停、半屏、四分屏、三分屏、整窗动作及录制/清除/冲突恢复 | 统一录制所有可自定义绑定；⌥Tab 为只读摘要和跳转 |
| 窗口 / 工作区（实验） | 实验开关、保存当前布局、恢复、覆盖更新、删除、原空间选项 | 列表管理；保存/覆盖用有名称的事务；恢复显示结果及失败窗口；不可用时给原因 |
| 状态与操作 / 面板布局 | 模块可见性、快速操作页可见性、密度 | 唯一模块可见性编辑位置；各模块页展示关闭提示和返回链接，不复制总开关 |
| 状态与操作 / 自定义快速操作 | 声音与电源、显示与锁屏、访达与文件、设备清洁、快捷指令；蓝牙目标；指令名称 | 只配置「显示」和参数；执行动作留面板。新增显示桌面命令由原桌面控制器承载 |
| 状态与操作 / 菜单栏图标 | 组合/尺寸/风格/实时示意；网络、蓝牙音频替代优先级 | 图标全局构成唯一归属；参数演示只在相关图标设置附近出现 |
| 状态与操作 / 电池 | 百分比与位置、充电标记、颜色、充电光效/呼吸、详情 | 电池专属图标细节保留此页，用链接从菜单栏图标页前往，不复制控制 |
| 状态与操作 / 网络 | Wi-Fi 图形映射、VPN、Wi-Fi 名称、速率、本机/公网 IP | 权限说明贴近读取名称的选项；联网查询行为不因打开示例图自动执行 |
| 状态与操作 / 声音 | 音量颜色、输入静音标记、输入显示、设备数量/顺序、滚轮与方向 | 原「网络与音量」音频字段整组迁移；输出设备实际切换在状态面板 |
| 状态与操作 / 蓝牙 | 可见设备选择、数量、未配对过滤、信号强度、编解码器/断开、附近电量扫描 | 勾选表示列表包含项；设备连接是命令，不能用同样的控件伪装成显示配置 |
| 状态与操作 / 存储 | 内置空间、外置卷、推出可见性 | 真正推出在状态面板，配置页不突然执行 |
| 状态与操作 / 性能 | CPU、内存、交换空间、运行时间 | 采集策略与可见性分开描述；没有数据时不伪造 0 |
| 屏幕 / 屏幕特效 | Duo 启用/暂停、角度读取/校准、参数预设、方向/速度/外观、预览与重置 | 功能特效速度独立于应用 UI 动效；标清内屏与权限限制 |
| 应用 / 通用 | 窗口增强总状态、外观、语言、登录启动 | 名称「窗口增强」不扩大为「Blinker 总开关」：状态与特效仍独立运行 |
| 应用 / 权限与诊断 | 权限状态/授权助手、应用兼容性检查、模块异常、最近操作反馈 | 固定入口；只显示必要错误及下一步。规则页跳转携带应用，兼容性区块置于首屏，无重复诊断窗口 |
| 帮助菜单 / 关于 | 指南、重新引导、版本/许可证/项目链接 | 通用页可保留链接，不复制完整关于内容或权限表格 |

快捷操作分组名称必须与自定义页一致。状态面板专注读数/设备；快速操作专注执行。系统菜单保留全局暂停、恢复、退出等紧急入口，引用同一状态，不另存一套配置。

## 4. 去重判定

删的是重复的编辑界面和说明，不是所有重复入口。上下文快捷入口能帮助定位，应跳到唯一拥有者。

- 取消规则页与设置页互相开窗的主工具栏按钮；统一侧栏承担切换。
- 移除单应用编辑第二套表单；导入/导出、复制、撤销只各维护一个命令，菜单与工具栏可调用同一命令。
- 状态模块配置集中在面板右上角「管理面板 → 自定义… → 状态」菜单；电池与网络的摘要行可展开详情，其他模块标题只作标题。系统设置明确带「系统」二字。
- 当前音频设备折叠时展示一次；设备列表展开后选中行承担说明，不再在相邻两行重复同一名称。
- 错误只在受影响操作旁展示；全局诊断可汇总，不能同时弹 toast、banner、alert 三次报告同一个错误。
- 解释按层放置：影响操作的约束在行下；组共用说明在 footer；原理放帮助。移除每行都重复的「开启后…」。
- 「恢复默认」只重置当前页；按钮和确认都包含范围。规则恢复、全页恢复、导入覆盖分开命名；可撤销动作无需再加一轮无意义确认。

## 5. 原生材质与内容布局

采用 macOS 26–27 系统原生外观。窗口、侧栏、工具栏、Popover、Form、List、Section、GroupBox 均使用对应系统容器与默认表面；玻璃由系统容器或系统提供的原生按钮样式承担。不自绘玻璃外壳、渐变高光、圆角卡片、选中底、阴影或分组描边，不通过手工叠色和固定 alpha 模拟系统材质。

- 规则与设置使用原生 Form/Section；设备集合使用原生 List/Picker；可折叠内容使用 DisclosureGroup；独立分组需要边界时使用 GroupBox，不能重新画一层卡片。
- Popover 使用系统外壳，根内容不叠加第二层模糊。独立窗口采用系统窗口背景或对应原生材质，不保留项目自定的 55% 遮罩、0.35 分组填充等视觉参数。
- 使用语义颜色与系统文字角色，正文 `.body`、说明 `.secondary`、数字可用等宽数字。字号和图标默认跟随原生组件，不能为了“新版感”把所有内容放大或变粗。
- 窗口缩略图、应用图标、菜单栏信息图、清洁黑幕及屏幕特效属于业务内容，允许展示或绘制真实内容；它们的操作入口、选择、退出、参数编辑必须使用原生控件。不得以“功能特效”为由保留自绘按钮。不存在系统专用功能时，用原生控件组合实现业务，不伪造系统控件。
- 减少透明度、增强对比度、浅深色、焦点与禁用状态由系统组件响应；先移除阻碍系统适配的自定义覆盖，不为不同页面各造一套替代颜色。

布局尺寸见第 7.2 节。布局参数控制窗口与内容占用，不覆盖系统控件的固有尺寸。

## 6. 形状、圆角与分割线

**不维护自定义控件形状或圆角 token。** 删除前版 control 8 / group 12 / floating 16 / glassShell 24 对交互组件与容器的要求。系统按钮的圆形、圆角矩形、胶囊或复选框形状属于系统组件外观，不自行绘制，也不以统一为由全部强制改为某一种形状。

| 外观 | 产生方式 | 使用边界 |
|---|---|---|
| 工具栏的圆形或组合外壳 | 原生 ToolbarItem / NSToolbar 自动布局与样式 | 不手工补圆框、组外胶囊或固定间距占位 |
| 正文文字按钮 | 原生 Button / NSButton 的系统按钮样式 | 不覆盖背景、圆角、阴影或按下效果 |
| 圆形图标动作 | 系统原生按钮样式；确有独立上下文动作时可用系统 `.buttonBorderShape(.circle)` | 不绘制 Circle 背景，不用圆形装文字命令；图标提供名称和 help |
| 页面导航轨道 | 系统玻璃按钮组或系统 tabs（页面导航）；普通参数仍用原生 Picker/分段控件 | 不画选中胶囊，不用 matchedGeometryEffect 模拟系统滑动 |
| 方形复选框 | 系统 Checkbox | 仅集合包含；不画方形命令按钮 |
| 图形方案与设备选择 | 原生 Picker / List 的系统选择状态 | 图形作为选项内容或相邻预览，不提供自绘可点选卡 |
| 分组与分割 | 原生 Form/Section/List 分隔；独立区域必要时使用 Divider | 不描边模拟卡片，不重复画 1px 线，不手动给每行补分隔 |

容器本身的系统焦点环、命中范围和阴影不能被额外 clipShape 截断。分组首先采用系统 Section 标题和布局，不嵌套多层 Form/GroupBox 制造外框。

## 7. 原生控件契约

「原生」指使用系统控件本身及其系统 style；只用 SwiftUI 绘制一个外形相似的控件不算原生。可以封装业务绑定、校验和原生布局组合，但封装内不能另写 ButtonStyle、ToggleStyle、PickerStyle、Layout 来仿造系统控件，也不能用手势视图替代真实 Button 的交互语义。

### 7.1 唯一组件模式

| 任务 | 原生组件 / 样式 | 规则 |
|---|---|---|
| 正文一次性操作：授权、锁定、重试、恢复默认 | Button `.bordered` / 标准 NSButton | 使用动词，regular，同组同高；不套全局自定义样式 |
| 明确事务提交：保存、确认导入 | Button `.borderedProminent` | 一个事务最多一个强调提交；取消使用普通按钮，破坏操作有 destructive 语义 |
| 工具栏：添加、更多、收放侧栏 | ToolbarItem 内的 Button / Menu | 系统自动外观与分组，不对其强制套正文按钮风格 |
| 辅助入口：系统设置、清除、行内静音 | Link 或局部 `.borderless` Button | 原生焦点与反馈，不能仅靠悬停发现；权限/危险动作优先文字 |
| 持续状态 | Toggle `.switch` | 开关统一 regular；状态未知显示读取中，不假装关闭 |
| 集合包含：面板显示哪些设备 | Toggle `.checkbox` | 原生复选框；与设备连接、启用开关区分 |
| 单选参数或输出设备 | Picker；大量项用系统菜单/原生选择列表 | 系统承担选中反馈；不使用自绘行按下效果或开关单选 |
| 图形方案 | 原生 Picker + 非交互预览，必要时系统 radioGroup | 保留图形对比能力，取消自绘选择卡 |
| 应用规则/设置、状态/快速操作切换 | macOS 26 用原生 Button 的 glass/glassProminent 样式组成导航组；27 可用已核实可用的系统 tabs | 均为系统控件和系统样式，保留当前侧栏顶部/面板页头位置；26 选中按钮带 selected 辅助功能状态，不自绘玻璃、背景或动画 |
| 侧栏导航 | NavigationSplitView + 原生 List selection | 单击直接切页，选择、焦点和滚动交给系统 |
| 折叠内容 | DisclosureGroup | 原生箭头与展开，不包自绘圆按钮 |
| 连续数值 / 精确数值 | Slider / Stepper / TextField | 单位、范围、校验由业务定义，滑轨与拇指不重画 |
| 快捷键录制 | 原生 Button/TextField 组合 + 键盘事件处理 | 录制逻辑可由应用实现；外壳、焦点、清除和冲突提示使用原生控件 |
| 加载 / 错误 / 确认 | ProgressView、Text、Alert、Sheet | 保留真实状态，禁用范围只覆盖冲突操作，不自绘 toast 按钮或警告框 |

系统玻璃按钮样式本身属于原生，可在独立上下文操作使用；这不授权自制 glassEffect 卡片和按下动画。普通原生按钮、Checkbox、Slider 不因无玻璃而算“旧组件”。

### 7.2 大小规范

控件大小以系统 `controlSize` / `NSControl.ControlSize` 为唯一入口，**不规定“所有按钮高 32pt、开关宽 44pt”这样的伪原生规格**。同一档位下不同控件高度可以不同，尺寸随系统版本、内容和辅助功能需要变化。

| 对象 | 默认大小 | 允许的调整 / 禁止事项 |
|---|---|---|
| 正文按钮、开关、复选框、Picker、输入框、Slider | `.regular` | 原生固有尺寸；不使用 scaleEffect、固定高度、额外内边距改变控件外壳 |
| 工具栏按钮、搜索、窗口红绿灯 | 系统工具栏/窗口尺寸 | 不在 ToolbarItem 内强行设宽高；不手调红绿灯几何 |
| 独立图标按钮 | `.regular`；采用原生样式的固有尺寸 | 原生工具栏除外，独立命中区以至少 28×28pt 为检查目标；不足时扩展布局与可点击留白，不能放大符号或扭曲外壳 |
| 紧凑列表中的次要行内操作 | 默认仍 regular；只有真实空间约束时局部 `.small` | 必须整组一致并注明理由；开关和主要动作仍 regular。紧凑模式优先减少行间留白，不缩小所有控件 |
| `.mini` / `.large` / `.extraLarge` | 本项目常规界面不使用 | 不因内容少而放大按钮，也不为塞进一行而缩成 mini |
| 按钮宽度 | 随本地化文字和系统内边距自适应 | 同组同档位，不要求等宽；不截断标题，不把普通按钮拉满整张表单 |
| Form / List 行高 | 系统默认；长内容自然增高 | 不写死 28/32/44pt 行高；焦点、控件和换行不能被裁掉 |
| SF Symbols、控件文字 | 跟随所在原生控件/Label/文字角色 | 不给同类按钮逐个指定不同字号；应用图标和窗口缩略图是内容尺寸，不决定按钮大小 |
| 主窗口 | 默认及标准缩放 920×620pt；最低 760×480pt | 保存用户手动尺寸；切页不自动改尺寸，长页滚动 |
| 侧栏 | 理想宽 210pt，可调整 180–240pt | 使用分栏约束，不用 Spacer 模拟宽度；长名称遵循系统截断与 help |
| 设置正文 | 最大宽 720pt，顶部及起始边对齐 | 窄窗口自然缩窄；不强行设最小内容宽度导致横向裁切 |
| 状态面板 | 宽 360pt；正文滚动高度上限 460pt | 短内容自然收缩；工具栏由系统决定高度，不强行放大填满 |
| 原生 Form/List/Toolbar 内部间距 | 系统默认 | 不重新覆盖 rowInsets、分组圆角、每行分隔与工具栏安全区以仿系统 |
| 原生容器外的业务组合间距 | 相邻内容 8pt、分组 16pt、窗口正文外边距 20pt | 仅在系统尚未提供间距处使用；不得在原生 Form 默认边距之外再加一层 |
| 面板密度 | 仅作用于原生容器外的组合留白：舒适/紧凑行距 6/4pt、组距 12/8pt、外边距 16/12pt | 不改变系统开关、按钮、行高和文字大小；落入 Form/List 的内部区域使用系统布局，禁止重复叠加 |

以上窗口尺寸和组合留白是 Blinker 的布局决定；regular/small 是系统档位，28pt 是独立命中区检查目标，不是所有系统按钮的可见高度。检查 1×/2×、长中英文、最小窗口和键盘焦点；不能只量截图像素后反推固定 point 数。

平台依据：[Apple ControlSize](https://developer.apple.com/documentation/swiftui/controlsize)、[macOS Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)、[Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)。

## 8. 原生反馈与转场

- Button、Toggle、Picker、List、DisclosureGroup 的悬停、按下、选中、焦点与展开全部交给系统；不再定义 120ms 按下/选中动画，不手写透明度、缩放或 matchedGeometryEffect。
- 页面导航使用原生导航容器及其默认转场；系统组件没有默认动画时直接切换，不人为补淡入。Sheet、Popover、窗口打开/关闭/收放保持系统动画，不叠加整窗 alpha 或页面到达动画。
- 快速切页立即更新路由；保留选中、搜索、编辑和各页滚动状态。旧异步任务不得覆盖新页面，命令生命周期不绑定页面动画。
- 原生进度反馈立即反映请求状态，不等待转场结束执行。尊重系统减少动态效果；不自定另一套辅助功能时长。
- 开合盖、充电光效等业务效果与 UI 控件转场分开；保留业务功能与关闭方式，其配置和操作仍全部使用原生控件。悬停延迟和点击保护是业务参数，不为视觉统一归零。


## 9. 未来扩展与实现约束

- 新功能先明确领域、状态拥有者、唯一配置页、执行入口、权限、错误恢复和五种状态，再添加路由；不预放「即将推出」空栏目。
- 稳定 Route ID 与中文标题分离，支持 `rules(appID)`、`settings(audio)`、`diagnostics(appID)`、`workspaces` 等类型化路由；不要用索引保存选择。
- 每页注册标题、图标、分组、关键词、字段范围、重置范围、最低尺寸和状态拥有者。导航搜索作为后续扩展点，不作为本轮已存在功能宣称。
- 网络/声音拆分保留旧持久化 key；旧 `networkAndVolume` 深链需要上下文迁移，无上下文默认网络并提供声音链接。旧规则窗口路由映射到同一主窗口。
- 面板执行与设置配置调用同一个 Command / Store。只有 View 组合不同，不复制任务执行、权限申请或忙碌状态。
- 优先组合系统控件，业务封装只承担状态、路由、校验与原生布局。下表中的自绘实现为迁移对象，不得被新增功能继续复用；不创建新的 ButtonStyle、ToggleStyle 或 PickerStyle 仿制控件。
- 无正在使用功能时停止不必要扫描；静态表单不为玻璃刷新启动计时器。真实卡顿需用主线程/帧时间证据验证；设计稿顺滑不等于原生性能已修好。
