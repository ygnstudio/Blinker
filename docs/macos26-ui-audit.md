| 操作反馈 HUD | 唯一仍使用旧 NSVisualEffectView 的反馈界面 | 使用共享 NSGlassEffectView，内容置于 contentView，保留公告、点击穿透和消失时机 |
| 悬停红绿灯、悬停管理 HUD | 已有系统玻璃，不缺材质 | 删除旧系统磨砂与蒙版分支；保留语义色、点击保护和减少动态行为 |
| Dock 预览 / 窗口切换 | 已有系统玻璃外壳 | 删除旧系统外壳分支；缩略图、徽章保持稳定，不逐项叠玻璃 |
| 主窗口侧栏、添加/兼容性工具栏、搜索 | 由 NavigationSplitView、系统 toolbar 和 NSSearchField 承担 | 保留系统控件；搜索固定在侧栏导航下方，不额外重画玻璃或再套圆角 |
| Sheet、Alert、Menu、权限助手 | 标准系统呈现或专用辅助窗口 | 保留原生容器与焦点行为；不为新效果迁移成第二套窗口系统 |
| Form、开关、滑块、设备列表、快速动作正文 | 当前系统仍支持的标准内容控件，并非旧系统回退 | 不批量替换成玻璃按钮/玻璃卡；阅读和状态识别优先 |
| 清洁模式、Duo、充电光效 | 专用产品功能，不是导航材质 | 保留各自效果和退出方式，不以全局玻璃重写功能 |

导航层采用 [Apple Liquid Glass](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)，独立操作使用 [GlassButtonStyle](https://developer.apple.com/documentation/swiftui/glassbuttonstyle)，27 的页签使用 [TabsPickerStyle](https://developer.apple.com/documentation/swiftui/tabspickerstyle)。这些 API 的可用性也已对照本机 SDK。

## 兼容与旧 API 清理（244015 历史快照）

- Package.swift 最低系统 26.0；Info.plist、Mach-O 打包标记、发布校验及回归样本同步更新。
- 删除所有源码中的 pre-26 系统分支、NSVisualEffectView 回退及圆角蒙版生成器；GlassBackdrop 直接返回 NSGlassEffectView，取消不必要的类型转换与 host 包装。
- 移除旧 titlebarAppearsTransparent 兼容调整。
- NSApplication 激活改用 activate()；Text 拼接改为插值并补充中英文格式串。
- 移除测试 UserDefaults 子类多余的 unchecked Sendable 声明；保留测试的主线程隔离。
- 仅保留 26 与 27 的差异分支。27 专用 API 同时用编译器和运行时条件保护，Xcode 26 构建仍可使用 26 的玻璃界面。
- Intel 架构策略未改变；系统版本收缩不等于删除 Intel。
- 旧用户配置迁移、硬件缺失、权限拒绝、系统请求失败和辅助功能适配不是旧系统界面，继续保留。
- AX、CoreAudio、IOKit、ScreenCaptureKit 等仍承担真实系统功能，不能仅因接口历史较久就移除。
