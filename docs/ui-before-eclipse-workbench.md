# Blinker 原生界面规范

版本：2026-10-07 原生重构。适用 macOS 26–27；实施状态见 [重构记录](docs/native-rebuild.md)。本文是要求，不是全部验收通过证明。旧的“一个窗口内切换规则/设置两套侧栏”已撤销；[旧规范](docs/ui-before-native-rebuild.md)只作历史记录。

## 1. 窗口与任务

| 任务 | 原生承载 | 规则 |
|---|---|---|
| 应用规则 | 独立 WindowGroup 场景 + NavigationSplitView | 左侧应用列表，单击直接编辑右侧；只有一份编辑器；⌘1 唤回、⌘N 添加 |
| 全局设置 | 独立 WindowGroup 场景 + NavigationSplitView | ⌘, 唤回上次页面；侧栏“应用、窗口、状态与操作、屏幕”；外部深链选中并展开目标 |
| 状态与快速操作 | NSPopover 或独立状态窗口 | 两种承载共享 View 和应用生命周期服务；选择器用系统 Picker |
| 添加、导入冲突、确认、许可证 | 发起窗口的 sheet / alert | 不另开普通编辑窗口；取消保留原数据 |
| 权限助手与真实测试 | 各自独立的辅助窗口 | 保留与系统设置并排、拖动图标、真实红绿灯测试需求 |
| 悬停、窗口预览、反馈 | 非激活 NSPanel | 不抢走目标应用焦点，关闭后不遗留输入拦截 |
| 清洁、屏幕效果 | 独立功能覆盖层 | 保留可靠退出方式；业务特效不等同于控件装饰 |

NSApplication/AppDelegate 管理生命周期，NSMenu 使用系统响应链。关闭普通窗口不退出常驻服务；反复打开复用原窗口。两个窗口的导航状态独立；查看权限与诊断不清除规则搜索或选择。不存在手工“应用规则/设置”导航轨道。

## 2. 系统控件与外观

- 侧栏、搜索、工具栏采用 NavigationSplitView、List、searchable 和 macOS 26 DefaultToolbarItem；不另画收放按钮或搜索外框。
- 表单采用 Form/Section，选择参数用 Picker，持久开关用 Toggle.switch，集合勾选用 checkbox，连续值用 Slider，精确值用 Stepper/TextField。
- 一次操作使用 Button，系统 toolbar 决定工具栏按钮外形。正文使用系统 bordered，明确提交使用 borderedProminent。图标使用 Label/SF Symbols 并提供辅助功能名称。
- 状态/快速操作在 26 用系统 segmented Picker，在 27 用 SDK 已确认的 tabs。系统样式不保证每个控件都呈玻璃；不得为了让所有控件透明重新手工拼按钮。
- 玻璃属于导航与浮动操作层。正文使用系统背景和语义颜色，不叠自定 alpha、模糊遮罩、圆角描边。每个内容组只用一层原生分组。
- 不自定义 ButtonStyle、ToggleStyle、PickerStyle 来模仿系统。业务图标、缩略图、状态图形是内容；其存在不能成为重画控件壳的理由。
- 系统负责悬停、按下、选中、焦点与转场。没有系统动画的切页直接更新；不等待动画后才执行命令。遗留动画列入迁移差异，不能宣称已经删除。

## 3. 大小与空间

| 对象 | 规则 |
|---|---|
| 正文控件 | regular + 系统固有尺寸；不统一强制高度，不 scale 开关，不截断按钮文字 |
| 工具栏、红绿灯 | 系统提供几何、安全区、命中范围；不补固定 Spacer 或手工宽高 |
| 设置窗口 | 默认 920×620pt，最低 760×480pt；用户调节后保存尺寸 |
| 规则窗口 | 默认 860×620pt，最低 720×480pt；应用栏 180–300pt，理想 220pt |
| 设置侧栏 | 180–240pt，理想 210pt；真实 List，长名称可换行 |
| 设置正文 | 最大 720pt，顶端/起始边对齐；系统 Form 内边距，不再叠加卡片内边距 |
| 状态面板 | 宽 360pt，滚动内容上限 460pt；控件 regular，不为塞内容缩小开关 |
| 空状态 | 原生 ContentUnavailableView；一个主要添加入口，不在两栏重复按钮 |
| 辅助 surface | 随内容与屏幕约束；遗留整体缩放/固定高度需另验，不能沿用为新功能规范 |

## 4. 功能归属与数据保全

| 目标页面 | 归入的现有功能 | 执行 / 配置边界 |
|---|---|---|
| 独立规则窗口 | 添加/搜索/启用规则；红黄绿灯动作、修饰键、例外；复制、恢复、撤销/重做、导入/导出；兼容性入口 | 应用级行为只在规则编辑区修改；高级动作折叠，保留真实值 |
| 窗口 / 悬停按钮 | 放大启用、尺寸、出现延迟、作用范围、点击保护、额外按钮、真实测试 | 快捷键只显示当前绑定并跳到快捷键页；测试是明确的「测试」按钮 |
| 窗口 / 预览与切换 | ⌥Tab 启用与冲突、Dock 悬停与进出延迟、标签页、隐藏/最小化窗口、显示器范围、缩略图/大小 | ⌥Tab 唯一启用开关在此；手动打开面板属于预览测试 |
| 窗口 / 布局与桌面 | 拖动贴靠、Dock 再次点击收起、桌面行为；布局快捷键入口 | 日常「显示桌面/恢复窗口」移至快速操作；此页留配置、权限和命名明确的测试 |
| 窗口 / 快捷键 | 桌面、悬停、半屏、四分屏、三分屏、整窗动作及录制/清除/冲突恢复 | 统一录制所有可自定义绑定；⌥Tab 为只读摘要和跳转 |
| 窗口 / 工作区（实验） | 实验开关、保存当前布局、恢复、覆盖更新、删除、原空间选项 | 列表管理；保存/覆盖用有名称的事务；恢复显示结果及失败窗口；不可用时给原因 |
| 状态与操作 / 面板布局 | 模块可见性、快速操作页可见性、密度 | 唯一模块可见性编辑位置；各模块页展示关闭提示和返回链接，不复制总开关 |
| 状态与操作 / 自定义快速操作 | 声音与电源、显示与锁屏、访达与文件、设备清洁、快捷指令；蓝牙目标；指令名称 | 只配置「显示」和参数；执行动作留面板。新增显示桌面命令由原桌面控制器承载 |
| 状态与操作 / 菜单栏图标 | 组合/尺寸/风格/实时示意；网络、蓝牙音频替代优先级 | 图标全局构成唯一归属；参数演示只在相关图标设置附近出现 |
| 状态与操作 / 电池 | 百分比与位置、充电标记、颜色、充电光效/呼吸、详情 | 电池专属图标细节保留此页，用链接从菜单栏图标页前往，不复制控制 |
| 状态与操作 / 网络 | Wi-Fi 图形映射、VPN、Wi-Fi 名称、速率、本机/公网 IP | 权限说明贴近读取名称的选项；联网查询行为不因打开示例图自动执行 |
| 状态与操作 / 声音 | 音量颜色、输入静音标记、输入显示、设备数量/顺序、滚轮与方向 | 原「网络与音量」音频字段整组迁移；输出设备实际切换在状态面板 |
| 状态与操作 / 蓝牙 | 可见设备选择、数量、未配对过滤、信号强度、编解码器/断开、附近电量扫描 | 勾选表示列表包含项；设备连接是命令，不能用同样的控件伪装成显示配置 |
| 状态与操作 / 存储 | 内置空间、外置卷、推出可见性 | 真正推出在状态面板，配置页不突然执行 |
| 状态与操作 / 性能 | CPU、内存、交换空间、运行时间 | 采集策略与可见性分开描述；没有数据时不伪造 0 |
| 屏幕 / 屏幕特效 | Duo 启用/暂停、角度读取/校准、参数预设、方向/速度/外观、预览与重置 | 功能特效速度独立于应用 UI 动效；标清内屏与权限限制 |
| 应用 / 通用 | 窗口增强总状态、外观、语言、登录启动 | 名称「窗口增强」不扩大为「Blinker 总开关」：状态与特效仍独立运行 |
| 应用 / 权限与诊断 | 权限状态/授权助手、应用兼容性检查、模块异常、最近操作反馈 | 固定入口；只显示必要错误及下一步。规则页跳转携带应用，兼容性区块置于首屏，无重复诊断窗口 |
| 帮助菜单 / 关于 | 指南、重新引导、版本/许可证/项目链接 | 通用页可保留链接，不复制完整关于内容或权限表格 |

快捷操作分组名称必须与自定义页一致。状态面板专注读数/设备；快速操作专注执行。系统菜单保留全局暂停、恢复、退出等紧急入口，引用同一状态，不另存一套配置。


## 5. 状态、系统能力与扩展

配置与执行入口调用同一个服务；View 不复制命令实现。RuleStore 负责规则持久化与撤销，偏好 Store 负责配置，系统控制器负责权限、忙碌与错误。关闭页面不取消已接受的电源、设备、窗口操作。

异步界面需要真实的读取中、空、失败、无权限、成功状态；未知值不画成关闭。失败有可执行恢复路径，破坏操作保留确认。新功能先确定所属领域、状态拥有者、配置页、执行入口、权限、错误与重置范围，不预放空栏目。

原生不是“只用最近一年新增的 API”。AX、CoreAudio、IOKit 等仍是系统能力；私有 API、系统命令和 AppleScript 必须单独记录边界。macOS 27 能力按 availability 判断，本机 SDK 可编译不等于 27 实机验证。详见 [系统接口清单](docs/native-rebuild.md)。

## 6. 验收和剩余差异

每次构建独立记录：实际窗口打开/关闭/最小化唤回、⌘1/⌘N/⌘,/⌘W、规则搜索与编辑保留、设置深链、最小尺寸、中英文、浅深色、减少动态/透明度、键盘/VoiceOver，以及 macOS 26/27 实机。单元测试和 HTML 不替代原生渲染验收。

本轮已重建启动、菜单、规则/设置窗口与路由；删除手工导航和侧栏按钮；窗口预览按钮改用原生样式；屏保启动改用 NSWorkspace 异步接口。悬停自绘彩色面/按压、窗口预览淡入淡出仍保留：相关进一步迁移被自动审批拦截，未完成全应用原生化。HUD、预览整体缩放和其余辅助 surface 仍需专项检查。
