# Blinker 界面设计历史

归档日期：2026-10-07。以下内容从原设计规范迁出，保留当时的方案、验证结果和限制，不作为当前实施要求。三栏布局、旧页签位置、180ms 动效及旧组件名称均可能已被后续版本取代。

现行规则只见 [design-spec.md](../design-spec.md)；构建对应的验收证据见 [macos26-ui-audit.md](macos26-ui-audit.md)。测试数量只对应其记录时的代码，不能当作当前构建全量验收。

## 初版记录（布局已由下方修订取代）

本轮已经落地原生界面：统一管理窗口、18 个导航目的地、应用单击编辑、独立声音/网络设置及重置、工作区管理、带应用上下文的兼容性入口、快速桌面操作、浅正文、原生导航玻璃、自绘控件圆角与响应 token。

窗口默认与标准缩放尺寸为 920×620pt；正文上限 720pt，靠起始边布局。规则列表 180–220pt、编辑区至少 360pt，避免重复导航安全边距挤压正文。工作区无结果时不保留空白反馈行。手动调整的窗口尺寸仍保留，切换页面不强制缩放。

- 环境：macOS 26.6.2，macOS 27 SDK；隔离预览包使用独立 bundle ID，未替换已安装应用。
- 原生实测：920×620 标准缩放、三栏与隐藏主侧栏后的两栏、单击切换规则、同窗口诊断与设置入口、浅/深色、声音页、工作区页；正文的大块横向空隙已通过实际渲染修正。
- 自动验证：636 个 Swift 测试与 23 个打包/发布脚本测试；SwiftLint strict、修改文件 SwiftFormat 和 diff check。全仓 SwiftFormat 另有 27 个未改动文件的历史问题，已与 HEAD 对照确认，未扩大格式化范围。
- 验收边界：尚未在 macOS 27 真机运行；760×480 的精确原生缩放、VoiceOver 完整流程、系统增强对比度/减少透明度组合及全部设备热插拔场景仍需专项验收。减少动态/透明度已有代码处理，不能据此声称这些系统组合均已实测。

### 截图反馈修订

- 状态面板的页签与刷新共用一行，移除正文中的「系统状态」重复标题；独立窗口保留系统标题栏，弹出面板由 NSPopover 自身提供外壳。禁止再对整个内容叠加 glassEffect 与额外圆角。
- 独立窗口与弹出面板遵循同一应用外观设置。内容底使用语义色，不按呈现入口选择不同明暗。
- 舒适模式：行距 8→6pt、分隔线两侧合计空隙 36→24pt、顶部内边距 16→10pt、底部 14→10pt；紧凑模式对应 4/16/8/8pt。顶部页签与刷新保持同排。保留原有功能、系统设置入口和页内滚动。
- 本轮 636 个 Swift 测试通过；原生窗口唤回失败，尚未取得新构建的截图，因此三个目标界面的视觉验收保持待通过。不能以编译/测试替代这一步。

### 当前两栏与信息分层修订

主窗口改为互斥的规则/设置两栏，只存在一个原生 NavigationSplitView。面板默认显示电量、连接与速率、音量与当前输出；电池详情、连接详情、设备列表和输入音量按需展开，所有原有操作保留。面板布局工具栏提供直接打开入口，首次引导同步同窗口文案。

验证：637 个 Swift 测试通过，SwiftLint strict 零问题。macOS 26 原生检查了规则空态、添加测试应用、工作区切换、规则单侧栏（分隔位置 188pt，原三栏正文前为 393pt）、设置页、独立状态窗口首屏、电池详情展开和快速操作页。首屏可见电池、网络、音量、蓝牙。未触发系统动作。

待专项验收：弹出面板外壳、精确最低窗口尺寸、浅色最终构建和 macOS 27 真机。新交付为独立标识的 Blinker-layout-review.app。

### 面板页签对齐修订（244012）

- 页签使用原生 regular 尺寸，居于面板水平中心；200 pt 布局区内由系统决定控件本身宽度。
- 两侧操作区各 28 × 28 pt：左侧仅快速操作页显示“自定义”图标，右侧为刷新或忙碌指示；切页和忙碌状态均不改变中间布局。
- 本机独立状态窗口截图验证：360 pt 面板内，页签可见范围约 x=107–253 pt，中心 x=180 pt；两页相同。
- swift build 通过；严格 SwiftLint 291 个文件零问题；本次菜单栏 popover 外壳未复核。

### Liquid Glass 页签修订（244014，取代上面的 244012 页签外观）

- 导航保持水平居中、200 pt 布局区和两侧等宽操作区。
- macOS 26：导航组合使用系统 glassEffect(.regular, in: .capsule)，选中背景只作位置标记，不叠加第二层玻璃；切换动画 180 ms，遵循减少动态效果。
- macOS 27：使用原生 Picker 的 tabs 样式；macOS 26 使用统一的玻璃导航组件。26 之前不再支持。
- 按钮提供选中辅助功能状态与左右方向键切换。正文仍使用稳定阅读背景。
- 26.6.2 独立窗口中已验证两页切换和 AX 选中状态；非活动深色窗口材质较弱。27 运行时及菜单栏 popover 外壳未复核。
- 构建通过；SwiftLint 292 文件零问题；现有菜单栏 UX 回归测试 7 项通过。
- 官方依据：https://developer.apple.com/documentation/swiftui/view/glasseffect(_:in:) 与 https://developer.apple.com/documentation/swiftui/tabspickerstyle

### Display mode row (244017)

Quick Actions uses one display-mode row: leading display icon and action label, trailing native menu with the current resolution. Display names, HiDPI, refresh rates and current-mode checkmarks live in the menu; multiple displays use named submenus. Keep a 28 pt minimum row height and the same label/control alignment as sibling actions. Native single-display layout and menu contents were checked without applying a display mode. Seven display-mode tests, build and strict lint passed.

## 2026-10-07 原生与自绘并存规则（已废止）

用户随后明确要求全部原生。本节归档当时的第 5–8 节，自绘控件、圆角 token、手工透明度和 UI 动画不再是当前要求；实现迁移状态见现行规范。

## 5. 材质、颜色、文字与布局

采用用户选定 A + Liquid Glass。玻璃位于系统窗口导航、工具栏、NSPopover 外壳和上下文控制层；大面积表单保持不透明阅读底；状态面板按下表使用受控半透明背景。不要在每个 Form section 内再套玻璃和阴影。最终 SwiftUI/AppKit 使用系统材质与语义颜色；HTML 的 blur 只是示意，不能当成原生效果验收。

透明度按层管理，不提供全窗 alpha 滑杆：

| 层级 | 透明度规则 |
|---|---|
| 管理窗口侧栏、工具栏、页签 | 系统 Liquid Glass；不叠加手工透明窗口或额外模糊 |
| 应用规则与设置正文 | 保持稳定不透明语义底，文字和控件不降低 opacity |
| 菜单栏弹出面板 | SwiftUI 根底透明，透出 NSPopover 自带材质，不再覆盖实色底或叠第二层模糊 |
| 独立状态窗口 | 单层 behind-window popover 材质，叠 55% windowBackgroundColor 语义色遮罩，压制背景明暗干扰；状态与快速操作共用 |
| 面板分组 | 保留轻量语义填充；不再为每组加玻璃 |
| 悬停、窗口预览、操作反馈 | 保留现有系统玻璃；图标语义颜色和窗口缩略图不透明 |
| 清洁覆盖层 | 保留不透明黑底，避免露出桌面影响清洁功能 |

减少透明度或增强对比度时，状态面板直接使用不透明 windowBackgroundColor；增强对比度时内容组增加 1 个物理像素的语义描边，选择标记保持可辨，其余系统材质遵从系统设置。不要通过降低文字、控件或整个窗口的透明度制造玻璃。按下反馈、短暂页面到达及浮层进出可以临时改变 opacity，结束后必须恢复为 1；禁用态仍由系统语义承担。

颜色使用系统语义：表单底为 textBackgroundColor，面板遮罩和不透明回退为 windowBackgroundColor；强调色使用 accent，正文 primary、说明 secondary、分隔 separator。旧设计稿十六进制色仅保存在历史稿中，不作为原生色值。绿用于成功/正常，橙用于注意，红用于错误/破坏性确认，状态必须同时有文字或图标。

原生 Form/List/Toolbar 使用系统文字角色与默认布局，不强制覆盖字号。自绘内容参考：正文 13pt、节标题 12pt semibold、辅助 11pt、内容页标题 17pt semibold；11pt 不能承担唯一操作说明。数值等宽数字；图标用 SF Symbols，无同义混用的自绘图标。图标与文本基线对齐。自绘通用间距使用 4/8/12/16/20/24/32pt；页内边距 20–24、组间 20–24、行内 8、说明距行 4。普通表单行至少 32pt，自定义设备/命令整行至少 32pt；菜单栏紧凑场景最低 28pt，不压缩系统控件。状态面板密度是明确例外：舒适/紧凑的行距分别为 6/4pt，组距 12/8pt，外侧边距 16/12pt，弹出页头上下边距 10/8pt；内容组内边距固定 12pt。

正文按窗口宽度弹性布局，普通设置内容上限 720pt，顶部与起始边对齐，不在分栏剩余空间中央漂浮，长说明允许换行；主窗口宽大时不拉长 Slider 到整个屏幕。原生「缩放窗口」采用 920×620pt 的标准阅读尺寸；保留手动拉伸与全屏，不在切页时擅自重设窗口大小。短页保留自然底部留白，不以占位卡或拉大行距填满。状态面板保持 360pt，正文滚动高度上限 460pt，短内容按需收缩。独立窗口将页签与管理菜单置于原生 unifiedCompact 工具栏，隐藏重复标题；弹出面板使用顶部安全区导航与系统 NSPopover 外壳。无常驻底栏、无自绘外边框；正文以 group 圆角和轻量语义填充分组，无组间横线，组内不再套滚动区。

## 6. 圆角与分割线：全表面规则

系统窗口、原生 Button/Picker/Switch/Form/List/Sheet 的外形交给系统；下表只规定必须自绘的部分，不对系统按钮再次 clip。

| Token / 形状 | 值（pt） | 用途 |
|---|---:|---|
| control | 8 | 自定义可点选设备行、缩略图裁切、紧凑图标示意底 |
| group | 12 | 自绘内容组、选择卡、预览条目；原生 Form 不额外套卡 |
| floating | 16 | 自绘操作反馈 HUD、独立浮动信息容器 |
| glassShell | 24 | 自定义大预览浮层的外壳；NSWindow 边角由系统决定 |
| capsule | 高度 / 2 | 仅状态徽章、紧凑页签轨道；不能拿胶囊当普通表单容器 |
| circle | 宽度 / 2 | 红绿灯、颜色样本、系统圆形按钮 |

内外圆角不机械相同：缩略图 8 / 条目 12 / 浮层 24；各层留足间距。图示中的 2.5、4 等属于图形本身；悬停红绿灯的大小与半径由真实按钮几何决定；成比例缩放整个功能预览时圆角可同步缩放。这些是明确例外，不能扩散到普通业务控件。

分割线只用于区域边界或相邻同行内容，不用于每一块内容加框：

1. 原生 Form/List 使用系统 separator，避免手绘重复分割。
2. 自绘线为 1 个物理像素（`1 / backingScaleFactor` pt），用 separator 语义色；高对比时仍可识别。
3. 行间线缩进到正文起点；全宽线仅用于主栏/底栏边界；最后一行不画线。
4. 分组先靠标题与间距区分；已有不同表面填充时默认不再描边。选中态和键盘焦点允许独立边界。
5. 圆角只裁背景；焦点环与阴影不被父层裁掉。不对滚动内容做逐卡片背景模糊。

## 7. 控件统一契约

| 语义 | 唯一组件模式 | 状态要求 |
|---|---|---|
| 持续启用 / 可见性 | 原生 Switch | 配置名称明确「启用」或「显示」；关闭父功能不清空子值 |
| 设备集合包含项 | 原生 Checkbox 列表 | 多选语义；与连接按钮分开；不是所有 Toggle 都强制变 Switch |
| 单选参数 | 原生 Picker；2–3 个短选项可 segmented | 所有页面同语义同形式；图形差异才使用可视选择卡 |
| 一次性动作 | 原生有边框按钮 | 动词；执行中状态与禁用范围只影响冲突操作；不把每个按钮染蓝 |
| 导航 | Sidebar / 文本链接 / 带清晰标签的工具栏按钮 | 不用 Switch 导航；省略号表示还要选择或确认，直接执行不滥用省略号 |
| 自定义设备选择 / 选择卡 | StatusChoiceButtonStyle / MenuBarOptionCard | 未选、悬停、按下、选中、焦点、不可用；选中有勾选或文本，不能只靠色块 |
| 数值范围 | SliderReadoutRow | 单位、范围、步进一致；键盘微调，必要时数值输入；轮滚只在明确控件区域生效 |
| 快捷键 | HotkeyRowView | 录制、已绑定、冲突、注册失败、清除；离开页取消录制但保留原绑定 |
| 更多操作 | 原生 Menu | 次要/低频放入；破坏操作分组且标注对象 |
| 保存 | 普通偏好自动保存；命名/导入事务显式保存 | 中文输入法组合未结束不做破坏性归一化；离开页面不丢输入 |
| 状态与错误 | 局部状态文字 / OperationProgress / RuleFileStatus | 空、加载、不可用、无权限、失败、成功各有可理解的文案与下一步 |

普通开关无需「已保存」toast；可见状态变化已经是反馈。系统调用只确认请求被接受时，显示「已发送请求」，不能伪装成系统结果成功。初始化未知值用「读取中」或破折号，不把未知显示成关闭/0%。失败保留用户意图、显示实际状态，给重试；页面级操作只在所属范围内锁定。

### 7.1 控件外观与形状白名单

本节是 Blinker 的产品约束，适用于 macOS 26–27 的规则、设置、状态面板、快速操作及后续新功能。统一的判定单位为「相同语义 + 相同所在区域」，不能按每页喜好挑样式。标准 SwiftUI/AppKit 控件由当前系统渲染；普通 `.bordered` 按钮、Checkbox 和 Slider 不因没有玻璃而被归为旧版。需要淘汰的是手绘旧外观、重复包装和同场景的不同做法，不是仍适用的系统控件。

先决定是执行、持续状态、选择还是导航，再按下表选控件；最后才确定形状。表中原生外形由系统决定，不用固定半径覆盖。26/27 可以因系统渲染不同而略有差异，但同一系统下不能为同一任务并列维护两套样式。

| 场景 / Blinker 示例 | 唯一默认模式 | 形状与材质 | 不允许 |
|---|---|---|---|
| 窗口工具栏：收放侧栏、添加规则、更多 | 原生 ToolbarItem 中的 Button / Menu，系统自动样式 | 由系统决定单项形状及组合玻璃外壳 | 给每个项目再包一个圆、强制固定圆角、在系统组外再套胶囊 |
| Popover 页头独立图标动作：管理面板 | 原生玻璃图标按钮；Menu 保留原生菜单语义 | 单个圆形，regular 控件，至少 32pt 命中范围 | 同一页头混用裸图标、实心方块、双重圆圈；将文字动作塞进圆形 |
| 正文一次性动作：授权、重试、锁定、开始屏保、恢复本页默认 | 原生 Button，`.bordered`，regular | 系统标准有边框文字按钮；尺寸随文字，同排同高 | 手绘方块底、额外玻璃、随意改胶囊/圆形、整行染强调色 |
| 明确提交事务：保存命名、确认导入 | 原生主要按钮，`.borderedProminent`；取消为普通 `.bordered` | 同组保留系统几何；一个事务最多一个强调提交动作 | 自动保存设置页每组都有“主要按钮”；把重置设成默认 Return 动作 |
| 正文低强调辅助动作：打开系统设置、清除快捷键、滑块旁静音 | 原生 Link 或局部 `.borderless` Button | 无常驻形状底；图标动作仍有完整命中与焦点范围 | 用低对比灰字伪装禁用态、靠悬停才能发现唯一入口、改变正文操作的默认样式 |
| 持续启用：窗口增强、深色模式、隐藏桌面图标 | 原生 Toggle，`.switch`，regular | 系统滑轨与拇指；行末对齐 | 自绘药丸、缩放开关、用 Checkbox 或高亮圆按钮替代同类开关 |
| 集合成员：哪些蓝牙设备显示在面板 | 原生 Toggle，`.checkbox` | 系统方形复选框，行首对齐 | 把“包含在列表”画成电源开关；把方形复选框当旧样式删除 |
| 修改单选参数：按钮动作、语言、显示方式 | 原生 Picker；短且固定的 2–3 项可 segmented | 下拉或系统分段外形；同字段在所有位置保持一致 | 每个选项做独立圆角按钮、用导航胶囊编辑普通参数 |
| 切换页面：应用规则/设置、状态/快速操作 | 共享 NavigationTabs；27 用系统 tabs，26 用共享玻璃实现 | 一组导航轨道和一个选中指示；不暴露页面私有半径 | 两个独立“主要按钮”；参数 Picker 与导航页签互相代用 |
| 选择输出设备 | 整行 Button + StatusChoiceButtonStyle + 选中勾号 | 自绘命中反馈半径 control 8，整行至少 32pt | 每台设备一个玻璃按钮、用 Switch 表达单选、仅颜色表示当前设备 |
| 图形方案选择：菜单栏图标预览 | MenuBarOptionCard + 选中勾号 | 预览容器 group 12，图像裁切 control 8；可近方形 | 普通文字命令使用选择卡；逐卡自定义描边、阴影与选中颜色 |
| 展开详情 | 原生 DisclosureGroup | 系统箭头和展开行为，无新增按钮外壳 | 把展开箭头包成圆形按钮；自绘一套不同旋转/弹跳动效 |

#### 形状的明确边界

- **圆形**：仅独立、常见的单图标上下文操作和系统固有圆形控件；红绿灯属于系统/功能几何例外。工具栏按钮先由系统排布，不因图标是正方形边界就再画圆。
- **圆角矩形**：正文文字动作采用系统按钮；自绘设备行用 control 8，图形选择容器用 group 12。这两个 token 不套到系统按钮、Switch、Picker 上。
- **胶囊**：只允许共享页签轨道、短状态徽章与系统自动生成的外形。徽章是状态信息，不增加按钮按下反馈；不把普通正文操作批量改为胶囊。
- **方形 / 近方形**：只允许系统 Checkbox、图形选择预览和真实几何功能控件。新增普通文字动作、刷新、添加、更多操作均不使用自绘直角方形按钮。图标资源的矩形边界不等于按钮外形。
- **无边框**：仅明确的辅助链接、行内图标操作和可选择列表行；不是全应用 ButtonStyle。焦点、按下、不可用状态仍必须完整。

#### 尺寸、排列与强调统一

- 正文 Button、Switch、Picker 默认 `.regular`；同一操作行不得混排 `.small` 与 `.regular`。`.small` 仅限重复列表中的低强调行内工具，以及设置里的缩略预览开关；在调用处注明这一用途。普通设置与快速操作不使用 `.mini`、`.large`、`.extraLarge`。
- 原生控件高度和圆角交给系统，不用 scaleEffect 模拟另一种大小。自绘行最小 32pt；紧凑页签单项 28pt 为既有明确例外。不能把系统小按钮强制拉成 32pt 高来伪造统一。
- 图标统一 SF Symbols；独立图标必须有辅助功能名称和 help，涉及权限、删除、锁定等不明确操作优先显示动词文字。圆形外壳内使用普通符号，不再用自带圆框的符号形成双圈，系统特殊符号除外。
- 文字动作宽度随本地化内容，不强制所有按钮等宽；同组高度、样式、基线一致。状态行标签在左、控件在右；集合 Checkbox 在左。不要为对齐把按钮拉满整张表单。
- 强调色只表达主要提交、原生选中或启用；破坏操作使用 destructive 语义和明确对象，不自行填一块红玻璃。一次性动作不保留选中态，开关不能只闪一下作为成功反馈。

#### 材质与状态统一

- 工具栏/导航/独立上下文操作按表使用系统 Liquid Glass；正文控件使用表中标准风格。禁止在 `.glass` / 原生工具栏外再次叠 glassEffect、模糊、渐变高光或模拟玻璃的描边阴影。
- 原生 Button/Toggle/Picker 保留系统悬停、按下、禁用、焦点动画；不套自绘 StatusChoiceButtonStyle。该样式只用于设备选择与图形选择卡，导航使用共享 NavigationTabs 的反馈。
- 自绘控件按下立即反馈、松开 120ms 恢复，不缩放命中范围；减少动态效果时取消过渡。增强对比度时不降低文字 opacity；减少透明度交给系统材质和共享表面处理，单页不得另造浅灰/深灰替代色。
- 读取中不假装关闭；命令忙碌时保留按钮位置、显示进度并仅禁用冲突动作。失败恢复可操作状态并显示原因；“收到请求”与“操作成功”分开。

#### 整理优先级与验收

1. **P1 同场景混用**：对照正文动作、页头图标、开关三类，统一样式和 controlSize；先排查页面级样式向子控件传播，不机械全仓替换 `.borderless` 或 `.bordered`。
2. **P1 语义错误**：确认每个 Switch 真正改变持续状态、Checkbox 真正控制集合包含、设备选择有唯一选中标记，命令不会留下假选中态。
3. **P2 形状与材质**：移除双层玻璃、双圈、无理由方形命令和逐页自定义圆角；保留上述系统及图形预览例外。
4. **P2 状态完整性**：逐类检查未选、悬停、按下、选中、键盘焦点、禁用/忙碌，并覆盖浅/深色及减少透明度/增强对比度。26 和 27 分开记原生证据，不能只看 API 名称或 HTML 判定通过。

任何新增形状或样式，必须先在本表增加「用户任务、所在区域、为何现有模式不适用、状态与可访问性」说明。此表是新增与整改约束，不代表当前所有调用已完成迁移。

平台依据：[Apple Adopting Liquid Glass](https://developer.apple.com/documentation/TechnologyOverviews/adopting-liquid-glass)、[Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Glass button style](https://developer.apple.com/documentation/swiftui/primitivebuttonstyle/glass)。上面的用途白名单、32pt 自绘命中范围及例外分配是 Blinker 的项目规则，不冒充系统强制规格。


## 8. 按钮与页面动效

以下时间用于自定义组件；原生组件、Sheet、Popover 的系统动画不重复叠加。

| 交互 | 时序与变化 | 禁止事项 |
|---|---|---|
| 按下 | 当帧显示压下填充/明度变化；松开 100–120ms ease-out 恢复 | 等待动画结束才执行业务；缩放整块设置表单 |
| 悬停 | 原生控件保持系统反馈；自绘控件使用已有组件的反馈，不新增独立时序 | 所有文本都漂浮、跳动；仅悬停才显示必要操作 |
| 选中 | 立即写选中状态；自绘页签指示器使用 120ms ease-out，普通选择行保持即时；焦点环立即 | 按钮状态和真实模型不同步 |
| 同级页面切换 | 路由与标题立即更新，新内容 120ms 轻淡入；旧内容立即停止命中 | 水平推拉、缩放、先淡出再等加载；全窗反复改尺寸 |
| 状态/快速操作页签 | 选中立即；内容同样 120ms 淡入；每页滚动位置独立 | 动画期间吞掉输入；切回状态页触发重复命令 |
| 应用列表选择 | 单击立即换详情；保持列表滚动，详情定位到本应用上次位置或首组 | 再点「编辑」；每次选择新开窗口；等待长转场 |
| Disclosure | 使用原生 DisclosureGroup 展开和系统转场 | 已聚焦输入框被意外折叠 |
| 预览浮层 | 沿用出现 120ms、消失 100ms 的可打断淡入淡出 | 刷新缩略图重新播放进入动画 |
| 操作进度 | 接受命令立即显示进行状态；进度可未知 | 假进度百分比；长时间无文字反馈 |

页签只为选中指示器建立局部动画，不把整个 NavigationSplitView 放进 withAnimation。正文在同步导航阶段判断输入来源，再启动可取消的 120ms 淡入；规则详情、设置详情、状态与快速操作共用 NativePageArrival。键盘页面导航直接到达。⌥Tab/窗口预览的浮层进出保留既有可打断淡入淡出，选中窗口和提交动作不等待动画；不要把这项既有行为扩散成普通键盘切页动画。原生窗口打开/关闭/收放沿用系统行为，不新增整窗透明度过渡。

快速 A→B→C 导航以 C 为准，不排队播放；动画可取消，旧异步读取结果不能覆盖新页面。页面展示任务可取消，已接受的写入命令由应用层持有，不能绑定 View 生命周期。尊重减少动态效果：自定义位移/缩放/淡入持续时间为 0，保留状态反馈；尊重减少透明度：玻璃变稳定系统底；增强对比度使用可读分割与选中标记。

充电呼吸、Duo 开合盖等功能动画有自己的启用及参数，是产品功能，不套 120ms 页面动效。系统减少动态效果时停用非必要循环装饰；会改变功能语义的效果需明确说明和提供关闭方式。
