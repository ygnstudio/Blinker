## 2. 窗口整合

| 界面 | 目标容器 | 规则 |
|---|---|---|
| 应用规则、所有设置、工作区、兼容性检查 | 同一个「Blinker」管理窗口 | 统一导航状态，所有入口复用现有窗口并定位到目的地；恢复最小化窗口，不重置位置和尺寸 |
| 单应用规则编辑 | 主窗口的应用列表 + 编辑区 | 单击应用直接编辑；取消默认独立编辑窗口和「设置/规则」互相开窗按钮。旧入口重定向到 `rules(appID)` |
| 状态 / 快速操作 | 同一面板的两个页签 | 菜单栏弹出与 Dock 打开共享模型和组件；一次只展示一种承载方式，关闭面板不取消已接受的命令 |
| 授权助手 | 独立辅助面板 | 需要和系统设置并排、拖动应用图标；按权限复用同一面板，完成后可关闭 |
| 真实窗口测试 | 独立测试窗口 | 原生红绿灯本身是测试对象，不能改成截图或主窗口内容卡 |
| 悬停按钮、Dock 预览、⌥Tab、操作反馈 | 上下文浮层/HUD | 保持锚点、键盘和窗口层级，不能塞进管理窗口 |
| 清洁模式、开合盖特效 | 功能覆盖层 | 保留退出方式及权限边界；不受普通页面切换动效 token 控制 |
| 首次引导 / 重新查看引导 | 首次引导窗口 / 主窗口 sheet | 完成或关闭后回到指定目的地，不叠加第二套管理窗口 |
| 关于 / 许可证 | 系统「关于」入口复用一个窗口；许可证 sheet | 无需为整合强行取消标准系统入口；应用配置只有一份 |
| 保存工作区、导入冲突、危险重置 | 依附发起窗口的 sheet / alert | 普通编辑不弹窗；只有短事务、选择文件和确认使用 sheet |

主窗口建议默认 1000×700pt，保持原最低 760×480pt。常规页：导航 190–220pt，内容弹性。规则页：全局导航 + 应用列表 180–220pt + 编辑区至少 360pt；宽度不足 900pt 时折叠全局导航，工具栏保留显示侧栏按钮，应用列表和编辑区继续并排。不可缩字硬塞三栏，不丢失当前应用。每栏分别滚动；底部操作不遮住内容。

`⌘,` 定位通用；菜单「应用规则」定位上次选择应用；模块配置链接直接定位对应页面。关闭主窗口不退出菜单栏应用。修改导航必须先结束快捷键录制，保存有效输入并保留无效草稿；不能为了转场重建业务控制器。

## 3. 功能全量归组与唯一归属

侧栏四组：窗口、状态与操作、屏幕、应用。组可折叠；记住展开状态，外部跳转自动展开目标组。每组最多一层页面，不使用侧栏、页面页签、内嵌侧栏三套重复导航。工作区为窗口组中有独立内容模型的管理页，标注「实验」。新增功能优先加入已有领域，不能直接平铺到侧栏末尾。

| 目标页面 | 归入的现有功能 | 执行 / 配置边界 |

## 4. 去重判定

删的是重复的编辑界面和说明，不是所有重复入口。上下文快捷入口能帮助定位，应跳到唯一拥有者。

- 取消规则页与设置页互相开窗的主工具栏按钮；统一侧栏承担切换。
- 移除单应用编辑第二套表单；导入/导出、复制、撤销只各维护一个命令，菜单与工具栏可调用同一命令。
- 模块标题只作标题；行尾齿轮提供有辅助功能标签的配置入口。系统设置明确带「系统」二字。
- 当前音频设备折叠时展示一次；设备列表展开后选中行承担说明，不再在相邻两行重复同一名称。
- 错误只在受影响操作旁展示；全局诊断可汇总，不能同时弹 toast、banner、alert 三次报告同一个错误。
- 解释按层放置：影响操作的约束在行下；组共用说明在 footer；原理放帮助。移除每行都重复的「开启后…」。
- 「恢复默认」只重置当前页；按钮和确认都包含范围。规则恢复、全页恢复、导入覆盖分开命名；可撤销动作无需再加一轮无意义确认。

## 5. 材质、颜色、文字与布局

采用用户选定 A + Liquid Glass。玻璃位于窗口导航、工具栏、面板外壳和上下文控制层；大面积正文保持浅、不透明或足够稳定的阅读底。不要在每个 Form section 内再套玻璃和阴影。最终 SwiftUI/AppKit 使用系统材质与语义颜色；HTML 的 blur 只是示意，不能当成原生效果验收。

浅色设计稿正文 `#FBFCFE`、表面 `#FFFFFF`、次级填充 `#EFF2F6`；深色正文 `#2D323C`、表面 `#3D424C`。这些是设计稿对照色，不硬编码替换系统高对比/透明度设置。强调色使用系统 accent；正文 primary，说明 secondary，分隔 separator；绿色只表示成功或正常，橙色需要注意，红色用于错误/破坏性确认，信息不能只靠颜色传达。

系统字体：正文 13pt，节标题 12pt semibold，辅助 11pt，内容页标题 17pt semibold；11pt 不能承担唯一操作说明。数值等宽数字；图标用 SF Symbols，无同义混用的自绘图标。图标与文本基线对齐。间距 4/8/12/16/20/24/32pt；页内边距 20–24、组间 20–24、行内 8、说明距行 4。普通表单行至少 32pt，自定义设备/命令整行至少 32pt；菜单栏紧凑场景最低 28pt，不压缩系统控件。

正文按窗口宽度弹性布局，普通设置内容建议上限 720pt，长说明允许换行；主窗口宽大时不拉长 Slider 到整个屏幕。状态面板保持 360pt，固定标题/页签/底栏，正文独立滚动，不在卡片里再套滚动区。

## 6. 圆角与分割线：全表面规则

系统窗口、原生 Button/Picker/Switch/Form/List/Sheet 的外形交给系统；下表只规定必须自绘的部分，不对系统按钮再次 clip。

| Token / 形状 | 值（pt） | 用途 |
|---|---:|---|
| control | 8 | 自定义可点选设备行、缩略图裁切、紧凑图标示意底 |
| group | 12 | 自绘内容组、选择卡、预览条目；原生 Form 不额外套卡 |
| floating | 16 | 自绘操作反馈 HUD、独立浮动信息容器 |
| glassShell | 24 | 自定义大预览浮层的外壳；NSWindow 边角由系统决定 |
| capsule | 高度 / 2 | 仅状态徽章、紧凑页签轨道；不能拿胶囊当普通表单容器 |
| circle | 宽度 / 2 | 红绿灯、颜色样本、系统圆形按钮 |

内外圆角不机械相同：缩略图 8 / 条目 12 / 浮层 24；各层留足间距。图示中的 2.5、4 等属于图形本身；悬停红绿灯的大小与半径由真实按钮几何决定；成比例缩放整个功能预览时圆角可同步缩放。这些是明确例外，不能扩散到普通业务控件。

分割线只用于区域边界或相邻同行内容，不用于每一块内容加框：

1. 原生 Form/List 使用系统 separator，避免手绘重复分割。
2. 自绘线为 1 个物理像素（`1 / backingScaleFactor` pt），用 separator 语义色；高对比时仍可识别。
3. 行间线缩进到正文起点；全宽线仅用于主栏/底栏边界；最后一行不画线。
4. 分组先靠标题与间距区分；已有不同表面填充时默认不再描边。选中态和键盘焦点允许独立边界。
5. 圆角只裁背景；焦点环与阴影不被父层裁掉。不对滚动内容做逐卡片背景模糊。

| 音频「使用中」、蓝牙未配对等徽章 | 同一 StatusBadge 字号、内边距、语义色；胶囊保留，文字必须说明状态 |
| 清洁覆盖层、Duo、充电光效 | 专用功能表面保留；退出控件遵守普通按钮和焦点规范 |

悬停出现/关闭延迟和点击保护时间是功能参数，不应为了“更快”一律归零；感知迟钝要区分有意保护、命令等待与主线程阻塞。任何半径迁移都先核对命中区域、焦点环和截图，不用全仓字符串替换。

## 7. 控件统一契约

| 语义 | 唯一组件模式 | 状态要求 |
|---|---|---|
| 持续启用 / 可见性 | 原生 Switch | 配置名称明确「启用」或「显示」；关闭父功能不清空子值 |
| 设备集合包含项 | 原生 Checkbox 列表 | 多选语义；与连接按钮分开；不是所有 Toggle 都强制变 Switch |
| 单选参数 | 原生 Picker；2–3 个短选项可 segmented | 所有页面同语义同形式；图形差异才使用可视选择卡 |
| 一次性动作 | 原生有边框按钮 | 动词；执行中状态与禁用范围只影响冲突操作；不把每个按钮染蓝 |
| 导航 | Sidebar / 文本链接 / 带清晰标签的工具栏按钮 | 不用 Switch 导航；省略号表示还要选择或确认，直接执行不滥用省略号 |
| 自定义设备选择 / 选择卡 | 统一 ChoiceRow / ChoiceCard | 未选、悬停、按下、选中、焦点、不可用；选中有勾选或文本，不能只靠色块 |
| 数值范围 | SliderReadoutRow | 单位、范围、步进一致；键盘微调，必要时数值输入；轮滚只在明确控件区域生效 |
| 快捷键 | HotkeyRowView | 录制、已绑定、冲突、注册失败、清除；离开页取消录制但保留原绑定 |
| 更多操作 | 原生 Menu | 次要/低频放入；破坏操作分组且标注对象 |
| 保存 | 普通偏好自动保存；命名/导入事务显式保存 | 中文输入法组合未结束不做破坏性归一化；离开页面不丢输入 |
| 状态与错误 | InlineStatus / OperationProgress | 空、加载、不可用、无权限、失败、成功各有可理解的文案与下一步 |

普通开关无需「已保存」toast；可见状态变化已经是反馈。系统调用只确认请求被接受时，显示「已发送请求」，不能伪装成系统结果成功。初始化未知值用「读取中」或破折号，不把未知显示成关闭/0%。失败保留用户意图、显示实际状态，给重试；页面级操作只在所属范围内锁定。

## 8. 按钮与页面动效

以下时间用于自定义组件；原生组件、Sheet、Popover 的系统动画不重复叠加。

| 交互 | 时序与变化 | 禁止事项 |
|---|---|---|
| 按下 | 当帧显示压下填充/明度变化；松开 100–120ms ease-out 恢复 | 等待动画结束才执行业务；缩放整块设置表单 |
| 悬停 | 100ms 填充变化；移出恢复 | 所有文本都漂浮、跳动；仅悬停才显示必要操作 |
| 选中 | 立即写选中状态，100ms 背景过渡；焦点环立即 | 按钮状态和真实模型不同步 |
| 同级页面切换 | 路由与标题立即更新，新内容 120ms 轻淡入；旧内容立即停止命中 | 水平推拉、缩放、先淡出再等加载；全窗反复改尺寸 |
| 状态/快速操作页签 | 选中立即；内容同样 120ms 淡入；每页滚动位置独立 | 动画期间吞掉输入；切回状态页触发重复命令 |
| 应用列表选择 | 单击立即换详情；保持列表滚动，详情定位到本应用上次位置或首组 | 再点「编辑」；每次选择新开窗口；等待长转场 |
| Disclosure | 原生展开；自绘必要时 160ms 高度变化 | 已聚焦输入框被意外折叠 |
| 预览浮层 | 沿用出现 120ms、消失 100ms 的可打断淡入淡出 | 刷新缩略图重新播放进入动画 |
| 操作进度 | 接受命令立即显示进行状态；进度可未知 | 假进度百分比；长时间无文字反馈 |

快速 A→B→C 导航以 C 为准，不排队播放；动画可取消，旧异步读取结果不能覆盖新页面。页面展示任务可取消，已接受的写入命令由应用层持有，不能绑定 View 生命周期。尊重减少动态效果：自定义位移/缩放/淡入持续时间为 0，保留状态反馈；尊重减少透明度：玻璃变稳定系统底；增强对比度使用可读分割与选中标记。

充电呼吸、Duo 开合盖等功能动画有自己的启用及参数，是产品功能，不套 120ms 页面动效。系统减少动态效果时停用非必要循环装饰；会改变功能语义的效果需明确说明和提供关闭方式。

## 9. 未来扩展与实现约束

- 新功能先明确领域、状态拥有者、唯一配置页、执行入口、权限、错误恢复和五种状态，再添加路由；不预放「即将推出」空栏目。
- 稳定 Route ID 与中文标题分离，支持 `rules(appID)`、`settings(audio)`、`diagnostics(appID)`、`workspaces` 等类型化路由；不要用索引保存选择。
- 每页注册标题、图标、分组、关键词、字段范围、重置范围、最低尺寸和状态拥有者。导航搜索作为后续扩展点，不作为本轮已存在功能宣称。
- 网络/声音拆分保留旧持久化 key；旧 `networkAndVolume` 深链需要上下文迁移，无上下文默认网络并提供声音链接。旧规则窗口路由映射到同一主窗口。
- 面板执行与设置配置调用同一个 Command / Store。只有 View 组合不同，不复制任务执行、权限申请或忙碌状态。
- 共享组件收敛到一层 UI support：间距/自绘圆角/动效 token、ChoiceRow、InlineStatus、SectionHeader。不要封装整个 SwiftUI 或重画原生控件。
- 无正在使用功能时停止不必要扫描；静态表单不为玻璃刷新启动计时器。真实卡顿需用主线程/帧时间证据验证；设计稿顺滑不等于原生性能已修好。

## 10. 落地顺序与验收

1. **结构**：主窗口路由统一、去掉重复编辑容器、工作区独立页、权限诊断固定入口。保留现有数据与全部功能。
2. **归属**：网络/声音/图标字段分配、页面重置范围、快捷动作与配置同组同名、系统设置入口明确化。
3. **视觉组件**：材质与浅正文、自绘圆角、父级分割线、统一 ChoiceRow/ChoiceCard 和状态提示。
4. **响应与动态**：按下反馈、页面淡入、快速切换取消、任务生命周期、减少动态效果。
5. **原生验收**：完成下表后，才能把设计稿规则标记为已实现。当前 HTML 仅证明排版与交互方向可审阅。

| 维度 | 必须通过 |
|---|---|
| 导航与窗口 | ⌘,、菜单、状态模块、规则兼容性均复用主窗口；最小化可唤回；快速切页不丢选择/输入 |
| 尺寸 | 1000×700、760×480；规则三栏在小宽度折叠主导航；正文/底栏无遮挡，无横向硬裁 |
| 视觉 | 浅/深色、明暗壁纸、减少透明度、增强对比度；玻璃不污染正文；普通正文至少 4.5:1 对比度 |
| 输入与辅助功能 | 键盘全流程、VoiceOver 标签与选中状态、原生焦点环；中文输入法组合、长中英文标题 |
| 动态 | 正常/减少动态；快速切换 10 次最后选择有效；不等待转场执行操作；关面板再开能看正确任务状态 |
| 功能保全 | 按第 3 节逐项核对，无字段丢失；旧配置迁移；页级恢复不影响别页；规则撤销/重做/导入仍有效 |
| 异常 | 每个异步 surface 验证读取中/空/错误/无权限/成功；设备拔出、权限撤回、系统命令失败可恢复 |
| 代码 | Swift build/test、必要回归、严格 lint、diff check；原生运行截图和关键路径真实操作后再交付 |
