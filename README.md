# Blinker

简体中文 | [English](README.en.md)

原生 macOS 菜单栏工具：放大窗口红绿灯、按应用设置按钮动作，用 ⌥Tab 和 Dock 预览找到窗口，再把窗口排到合适的位置。

[下载正式版](https://github.com/ygnstudio/Blinker/releases/latest) · [使用指南](docs/USER_GUIDE.md) · [更新日志](CHANGELOG.md) · [反馈问题](https://github.com/ygnstudio/Blinker/issues)

## 安装与更新

推荐通过 [Homebrew](https://brew.sh/) 安装：

```bash
brew install --cask ygnstudio/ygn/blinker
```

更新前先退出 Blinker：

```bash
brew update
brew upgrade --cask ygnstudio/ygn/blinker
```

[项目 tap](https://github.com/ygnstudio/homebrew-ygn) 会定期校验并同步正式版，发布后可能稍有延迟。应用内没有自动更新器。也可从 [Releases](https://github.com/ygnstudio/Blinker/releases) 下载 DMG，将 `Blinker.app` 拖入“应用程序”，后续手动替换更新。

目标系统为 **macOS 15 或更新版本**，发行构建包含 Apple Silicon 与 Intel。最低系统、Intel 实机兼容性及完整性能验收仍待完成，已验证范围见各版发行说明。

发行包采用 **ad-hoc 签名，未使用 Developer ID，也未经过 Apple 公证**。首次打开如被系统拦截，确认下载来源后，在“系统设置 → 隐私与安全性”中选择“仍要打开”。Homebrew 安装也可能需要这一步，详见 [Apple 说明](https://support.apple.com/zh-cn/102445)。

## 功能

| 功能 | 用法 |
|---|---|
| 应用规则 | 为红、黄、绿灯设置点击、修饰键点击和长按动作；各应用独立配置，支持复制、导入导出和撤销 |
| 悬停按钮 | 彩色按钮覆盖原生红绿灯，大小、延迟、点击保护和扩展按钮可调；macOS 26+ 使用系统 Liquid Glass |
| 预览与切换 | ⌥Tab 切换窗口，悬停 Dock 预览同应用窗口；面板整体缩放 50% 至 150%，可单独列出 Safari 和标准 macOS 标签页 |
| 窗口管理 | 半屏、四分屏、三分屏、居中、最大化、跨显示器移动及还原布局；支持快捷键、拖拽贴靠和实验工作区 |

应用规则和设置使用独立窗口。未配置普通左键动作时保留原生按钮行为；外观和中英文界面可在“通用”中调整。具体操作与兼容性说明见[使用指南](docs/USER_GUIDE.md)。

### v0.7.0 新增

- **状态图标**：在菜单栏、Dock 或两处显示电量、网络与音量。状态面板可调音量、静音和切换输出设备；在“设置 → 状态图标”调整显示内容、外观与顺序。左键默认打开面板，也可改为应用规则，右键保留菜单。
- **收起与恢复**：可开启再次点击前台应用 Dock 图标收起窗口，再点恢复。显示桌面默认使用 ⌃⌥D，再次执行只恢复本次收起的窗口；两者均跳过全屏和原本最小化的窗口。
- **Duo 开合盖效果**：兼容 MacBook 的内置屏幕随开合逐渐倾斜、模糊、暗化或恢复。默认关闭，提供模拟预览、角度校准和推荐参数；需要可读取的角度传感器，不改变正常合盖睡眠，也不是隐私防护。

### 开发版新增（未发布）

- **状态面板深度行**：电池循环次数、健康度、温度与充放电功率；上下行速率与本机 IP；可选公网 IP（默认关闭，面板唯一的出网请求）；蓝牙信号强度；面板密度两档，每类状态行均有独立开关。
- **蓝牙设备与附近设备**：配对设备列表含分类图标、电量与信号强度，可排序、限量并隐藏未配对残留；连接中被厂商误标的类型按系统枚举接口纠正。可选开启附近设备电量扫描，以及编解码器显示与单设备断开（共用蓝牙授权）。
- **快速操作页**：面板第二页，含麦克风开关、显示器清洁（全屏黑窗，零权限）、键盘清洁（系统级锁定，需辅助功能与输入监控）、清空回收站（经访达清空，首次需允许控制访达，删除前二次确认）和至多三个快捷指令槽。
- **Wi-Fi 名称与 VPN 行**：Wi-Fi 名称需定位授权以取消系统遮蔽；VPN 行只读显示隧道、系统服务或代理端点。
- **声音输入**：默认输入设备的音量与静音控制。
- **存储与性能区块**：内置磁盘可用空间（口径同访达）与用量条；外置卷逐行显示并附推出按钮，失败原因行内显示。CPU 使用率、内存与交换空间用量、运行时间（默认关），全部本地内核接口读取，无需权限。

## 开始使用

1. 首次启动按引导授予辅助功能权限，或在“设置 → 隐私与权限”中点击“授权…”。授权仍需你在系统设置中确认。
2. 右键菜单栏图标，打开“应用规则”，添加应用并设置按钮动作。各应用可分别启用按钮规则和悬停放大。
3. 在设置中开启需要的预览、窗口管理和快捷键。需要真实缩略图时，再主动授予屏幕录制权限；未授权也可按图标和标题切换。

| 权限 | 用途 |
|---|---|
| 辅助功能 | 识别窗口、按钮与受支持的标签页，执行窗口操作；Duo 跨应用 Esc 暂停与键盘清洁的系统级按键拦截也使用此权限 |
| 屏幕录制（可选） | 生成窗口缩略图，与 Duo 共用。悬停按钮的玻璃效果不需要录屏 |
| 定位（可选） | 状态面板显示当前 Wi-Fi 名称；不授权时只隐藏该名称 |
| 蓝牙（可选） | 扫描附近设备电量、显示编解码器与断开已连接设备；配对设备列表与信号强度无需此权限 |
| 输入监控（可选） | 键盘清洁的系统级按键拦截，与辅助功能共同必需；不授权时无法进入键盘清洁 |
| 自动化（可选） | 清空回收站经访达执行，首次清空时系统弹窗请求；不授权时行内报出原因并附设置入口。回收站项目数的显示另需完全磁盘访问，不授权只隐藏计数 |

屏幕画面只在内存中处理，不录音、不保存录像。Blinker 不上传规则、窗口标题或屏幕内容，没有统计分析；除可选开启的公网 IP 查询（默认关闭、开启时明示端点）外，没有自动网络请求，主动打开项目和帮助链接会交给浏览器。

自绘标签栏、其他桌面与最小化窗口的预览受系统和目标应用限制。后台标签页没有独立缓存时显示图标与标题；标签项上的关闭、最小化作用于整个窗口。实验工作区匹配已有窗口，不恢复文稿或会话，原桌面恢复使用非公开系统接口。授权排障和更多限制见[使用指南](docs/USER_GUIDE.md)与[窗口预览说明](docs/WINDOW_BROWSER.md)。

## 从源码构建

需要 Swift 6 工具链和包含 macOS 26 SDK 的 Xcode。以下命令用于 Apple Silicon：

```bash
git clone https://github.com/ygnstudio/Blinker.git
cd Blinker
./Scripts/build-app.sh release
open ~/Applications/Blinker.app
```

开发构建使用独立标识 `com.ygnstudio.Blinker.dev`，与正式版分别授权。Intel 构建、测试和签名说明见[贡献指南](CONTRIBUTING.md)。
